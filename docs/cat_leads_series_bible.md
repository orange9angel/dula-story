# 《猫带我去的地方》系列圣经（SERIES BIBLE）

> 长篇连载的最高设定锁。各集的 `STYLE_BIBLE.md` 管画面、`script.story` 管时序、
> 本文件管「世界是否自洽」与「伏笔埋收」。与《殖装学园》系列圣经
> （`episodes/bio_armor_academy_s1e1/SERIES_BIBLE.md`）互为表里——
> **两个系列同一个世界**。

## 1. 世界观

小城，河堤，白墙巷子。白天是治愈系：小蓝、橘猫小橘、转学生阿澈。
底下是《殖装学园》的世界：三个月前「陨石」坠入后山（外星生物科技货柜），
殖装单元碎片散进校园与山野。社团战在城市的暗面进行——废工地、河岸、
后山坠坑，全在猫系列主角的日常半径之内。

**猫系列是这个世界白天的表面**：主角们暂时什么都不知道。观众通过伏笔
先于角色意识到**世界比想象中更大、更好**——这是本系列长篇张力的来源
（向往，不是警觉）。

### 与殖装学园的交汇设定

- **同一条河堤**：E05/E06 的河堤台阶，顺流而下两公里就是社团战的河岸决斗场。
- **小橘知道得比人多**：猫对碎片生物能量的直觉是系列级设定。它"带我去的地方"
  终将包括后山坠坑——但那是很多集以后的事，不急。
- **变异动物**：碎片不只附人。山林里的动物被碎片附体后瞳孔发青色光
  （#3DFFC8——与殖装核同色，这是跨系列的视觉签名）。呈现纪律（向往语法）：
  神态安详、画面拍美，是"被点亮的生灵"而非"眼神不对"的惊悚。
- **阿澈的速写本**：他画得比谁都多、看得比谁都细。伏笔的主要载体。

## 2. 角色弧线（长篇）

## 2.0 暗线氛围定调（导演 2026-09-05；向往语法追加 2026-09-06）

暗线是科幻，不是恐怖。关键词：**降临感**——高阶智能出现时的敬畏、干净、
明亮、超越。禁忌：阴森、悬疑式停顿、卖关子的"神秘"腔。视觉签名
#3DFFC8 青色光永远是"干净的、美的"，不是"诡异的"。台词同理：角色谈论
异象时用平静笃定的陈述句，不用语气词和自嘲制造廉价悬念。

**向往语法（硬纪律，导演 2026-09-06 复片反馈）**：信息差保留，但每一拍的
预期方向必须是**渴望**而非**害怕**——世界比想象中更大、更好，不是更危险。
悬疑与向往用同一套结构机器（留白、埋设、回收），区别只在每一拍的情绪
符号为正。

| 禁止的悬疑语法 | 对应的向往语法 |
|---|---|
| 老人压低声音转述看不见的夜间异象 | 老人像讲一个老朋友，语气眷恋、表演与镜头给暖意 |
| 孩子交换不安眼神（"青光？"对视） | 孩子眼睛发亮、向往（"哇，想看！"） |
| 奇观藏着不给看、一帧闪过 | 奇观正大光明地拍美、铺满画面，角色与观众一起惊叹 |
| 角色回避提问 + 沉默收尾 | 角色出神是眷恋（像猫第一次看雪），回应温柔 |
| 动物警觉/害怕的表情 | 动物眼神放软、向往——它在看它喜欢的东西 |
| 静帧配音频骤停 | 静帧配 BGM 继续流动（音乐一停是恐怖片，继续走是诗意） |

老周定位修正：他不是暗线的**证人**，是暗线的**守护者**——河里的光是他
的老朋友，他夜钓是与它为伴。「老相识了。这条河，它比我熟」在此解读下
成立，且为重估式回收预留了接口。

| 角色 | 表面弧线（现在） | 暗线弧线（长线，不急） |
|---|---|---|
| 小蓝 | 跟着猫发现城市里的小美好 | 第一个意识到"世界比想象中更大"的人 |
| 小橘 | 向导、秘密基地的主人 | 对碎片能量的直觉；它到底活了多久？ |
| 阿澈 | 安静画画的转学生 | 速写本里早就画下过"不该存在的东西"；与「蚀」线相连 |

用户原始脑洞存档（2026-09-05）：小蓝路上碰到变异大熊 → 阿澈去救 →
感染外星病毒（蚀）。这是交汇剧情的候选主事件，**等待工艺成熟再拍**
（需要：变异生物设计 + 动作戏语法 + 异变调色板）。

台账纪律：
- 任何单元格不许跳级（不知→知情必须经过目击/起疑），且每次移动必须有画面级原因。
- 观众列永远领先所有角色列；有角色追到"知情"时，剩余伏笔须围绕这一变化重排。
- 角色禁止在台词中解释暗线；信息只能经"不理解自己所见的证人"或"无人解读的画面"传递。

## 5. 连载纪律

- **画风统一**：无论剧情明暗，画面永远走晴印（sunprint）主线——长篇连载的
  画风一致性本身就是作者性。题材变暗时只用调色板变体（夜晚版/异变版）
  承载情绪，不动画风五要素。殖装学园 pilot（bio_armor_academy_s1e1）的
  画面工艺整体作废（未走现行管线），其设定保留、画面以晴印重拍为准。
- 治愈系节奏不动：每集一个小事件、一个情绪落点，不为暗线牺牲单集完整性。
- 伏笔只许用"一句话 prompt 元素"埋，不占时长、不改剧情。
- 每 3-4 集至少埋或推进一个伏笔；每集收尾检查伏笔登记表与信息不对称台账。
- 伏笔生命周期（埋/冷却/推进/回收）与台账维护流程由 `dula-skills/series-architect/`
  定义，规划新集时先读该 skill。
- **文档与 prompt 中不出现第三方作品/作者名**：参考与灵感只存在于讨论层，
  落盘的设定必须是我们自己的表述。
