## 实际做了什么

| 窗口 | 表演与画面变化 | 实现及覆盖限制 |
|---|---|---|
| 132–137秒 | 目光从低处转向前方，眉眼收紧；保留说话开合，补一次眨眼和轻微点头 | 新绘头发/脸形底图与原生Canvas眉、眼、嘴绘制；只支持当前近正面角度 |
| 56.5–58.18秒 | 格挡前起势及承击时轻微改变肩身投影 | 原三维姿势上做视图相关几何修型，脚底区域不位移，盾面接触投影点约束；没有重画手臂原画 |
| 58.18–59秒 | 眯眼、咬牙与偏头压痛，随后睁眼重新注视 | 整头替换与屏幕修型并用；盾和领甲继续参与深度遮挡 |

底图用内置imagegen根据原片参考生成1张1254×1254透明PNG，原画包含头发、耳、
脸形、鼻和颈，眉眼口留空，实际五官由代码绘制并按绝对时间变化。
[生成回执与完整提示词](../../assets3d/art_pass_r1/generation.json)保存输入、工具与候选状态。
没有生成整段视频，也没有逐帧独立调用生图。

[合成适配](../../art_pass_r1.js)隐藏旧头部，用跟随原头部锚点的分区深度平面放置新头；
颈条后移至领甲后，面部保留在领前。眉眼嘴与发梢小幅形变用30fps连续采样，未宣称
完成多张手绘中间画或on-twos曝光。口型沿用现有`voice_envs`与发声窗口。

## 复看与判断

已直接查看最终视频解码的[决意帧列](r1/resolve_sequence.jpg)（每5帧取1帧，共30格）
和[格挡帧列](r1/guard_sequence.jpg)（每3帧取1帧，共25格），以及原尺寸关键帧。
另查[决意A/B](r1/comparison_resolve.jpg)与[格挡A/B](r1/comparison_guard.jpg)。

- 头发的片状体积变成绘画色块，脸形与耳鼻线条更明确；在当前近景中，低眼到
  抬眼、压痛到恢复的变化可从帧列辨认。嘴型开合与闭眼没有互相覆盖。
- 本轮早期的嘴被领甲截断已经修复；最终抽帧里下颌可见，颈被领甲遮住，盾面
  能遮住脸侧，没有观察到旧头与新头同时露出。所查看样本不等于所有可能角度。
- 格挡全景仍明显依赖原模型和动作，修型幅度很小。身体的表演自由度尚未达到
  原方案中的手臂/整人物作画目标，不能把这段称为全身手绘动画。
- 新脸更柔和，眼形比原版稍小；开口形状有时偏轻松，决意的力度仍可加强。
  这属于候选画风，人物身份与情绪强度仍需放到正常速度观看中判断。
- 平涂头部与强反光金甲之间仍有画风落差。下一步应设计肩颈/手型和甲片明暗
  原画，再检查完整人物；不能仅靠把全身材质换成单色解决。

本轮未进行正常速度的主观动态观看/声音审听，因此没有作出“已经达到目标动画
质量”的结论。交付文件可直接播放；最终艺术取舍仍需观看动态试片。

## 技术检查

[交付报告](r1/delivery.json)保存最终视频参数、摘要和音轨检查。
两段音轨直接从固定R27相应窗口提取后编码；与源PCM对比的相关系数分别为
0.999856、0.999331，检测时偏均为0毫秒。AAC重编码后不是字节相同音轨。
视频帧数为150、75，合并为225。拼接前按精确时长裁掉AAC解码尾包，最终视频与
音轨均为7.5秒；两段在合并版中的零时偏相关性另行复验通过。

[顺序/seek检查](r1/determinism.json)包括17个顺序与反向seek样本、4个重复取帧。
20/21项严格相同；58秒有1像素的最大通道差1/255，严格哈希检查**没有全通过**。
[独立基线检查](r1/baseline_pixel_noise.json)在未启用作画的原viewer上也复现了
2–40像素、最大通道差1/255的残差。最终试片在记录的有限容差内通过；残差的
内部成因尚未完全归因，不声称逐像素确定性已解决。

修型中脚底权重为零，盾接触点投影被约束，最终帧列没有观察到明显脱手；这仅是
本镜头样本和实现约束，不等于完整二维碰撞验收。模型、骨架、路线、时序未修改，
原三维探针也不能证明新投影在所有帧的接触正确。新轮廓的影子仍沿用底稿。

[构建记录](r1/build.json)保存本轮源代码及底图摘要；[表演样本](r1/samples.json)
保存13个关键时点的参数和图像摘要。导出过程没有浏览器错误。

## 试错保留

1. 整头共用平面深度时，下颌被高领挡住。改为脸前、颈后，并在最终画幅调整锚点。
2. 试过整甲平涂，但金甲体积/纹样层次退步，默认已撤回；实验开关
   `artPaintArmor=1`只保留为研究，不用于交付。
3. 克隆材质丢失自定义shader钩子，已显式继承。否则新增修型会影响原有材质。
4. 屏幕接触约束使用了上次渲染的相机逆矩阵，出现顺序/seek差异。
   [首次失败记录](r1/determinism_before_camera_fix.json)保留；现在先刷新当帧相机和角色
   世界矩阵。上述1/255残差单独记录，不合并宣称完全修好。

通用教训已写回`draw-over-animation`的作画与接入参考。代码仍为本集试片，待艺术
效果与更多镜头验证后再考虑晋升共享组件。

## 复现

在本episode下先启动已有渲染服务：

```powershell
node --import ./tools/register_loader.mjs render.mjs --serve --port 4249 --board storyboard/art_pass_pilot/server
```

另一个终端执行（`python`需有numpy；本次用内容仓库`.venv`）：

```powershell
node tools/render_art_pass_r1.mjs --render
node tools/probe_art_pass_r1.mjs
python tools/package_art_pass_r1.py
```

中间PNG与视频写入独立试片路径；MP4按仓库规则保留为本地输出，源代码、生成底图、
关键证据和记录入库。
