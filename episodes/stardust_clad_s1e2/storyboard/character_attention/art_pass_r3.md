# R3 局部复看

范围：阿鏊、夜刈，源时间 163–174 秒。用户认可 R2 整体，反馈来自用户：
平涂火焰不及原粒子，人物稍有纸片感。本轮沿用 [R2 审查](art_pass_r2.md)，复查新增
粒子、地面影、光色与相邻部位。源摘要和技术证据见
[R3 记录](../art_pass_r3/REVIEW.md)、[整集报告](../art_pass_r3/full_episode.json)。

实际查看为静帧与有序解码帧列：165.9 秒盾/腿、167.2 秒完整蓄力、173.8 秒两人收势，
并查看整段及 162.6–163.3、173.6–174.3 秒切口。

- 身份与结构：9 张原画文件未变；五官、发型、甲片和动作剪影沿用已认可 R2。
- 遮挡与可读性：粒子在人物前后分层，前层较弱；本次样本中脸和盾的轮廓可读。
  烟与发光采用不同合成方式后，火焰亮度更接近原效果。
- 支撑与场景：硬边脚底影改成柔化接触影，增加小幅方向投影；人物光色略受炉火
  影响。收势脚与地面的联系有所加强；投影不是物理解算，纸片感未宣称完全消除。
- 时序与声画：关键画和镜头时点沿用，前后切口按原时间衔接；音轨完全保留的证据
  是整流哈希，不是本轮听觉复核。
- 开放复查：整集内仍有新旧画风的切换。此次已完成指定窗口接回正片，其他窗口
  的身体、步态与场景未在本轮重制或重新评价。
