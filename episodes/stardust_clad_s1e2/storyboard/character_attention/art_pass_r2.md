# R2 作画试片注意力复看

主代理直接审查；范围为源片 163–174 秒，阿鏊与夜刈在本试片的可见视角。
输出版本与哈希见 [delivery.json](../art_pass_r2/delivery.json)，素材/执行摘要见
[build.json](../art_pass_r2/build.json)。证据为静帧和有序帧列，没有正常速度播放证据。

| 注意关系 | 可见事实及范围 |
|---|---|
| 整体与身份 | 红棕头发、金甲圆盾和蓝黑头发、紫甲身份稳定；新原画身体比例更修长，属于有意重画，不能称与原模型逐线一致 |
| 头颈和脸 | 163.6、164.95 秒看到鼻梁、下颌、颈部与高领的连接；本轮没有贴片穿领，其他角度未验证 |
| 视线 | 阿鏊近眼和远眼的瞳孔改为共同朝向右侧，极近景突出抬眼；夜刈命中前仍偏向腕扣，警觉抬眼表现不足，保留限制 |
| 表情与口型 | 阿鏊有低睑到睁眼、原对白口型，夜刈从解扣紧张到受击露齿；独立脸部表演密度仍低，正常速度声画未验证 |
| 头发 | 完整束状轮廓替换了原模型形状，局部跟随可见；没有完成背面、转头角度和逐束动力学 |
| 身体与衣甲 | 阿鏊低跪、起身过渡、弓步的剪影有明显区别；夜刈后仰和屈膝收势已分画，生成姿势间部分甲片线条变化仍可见 |
| 手与道具 | 盾在三张姿势间经过胸前；夜刈解扣手和断扣摊手可辨，链端跟踪同一腕扣标记；未验证复杂手指翻面 |
| 支撑与动作结束 | draft_b 的收势仍抬腿后仰，是本轮自发现遗漏；补落地画后 172.7、173.8 秒双脚呈低姿支撑，接触影改为脚点附近 |
| 步态 | 本 11 秒不包含持续行走。20–27 秒只导出数据，没有换脚原画，未评为二维步态通过 |
| 动作时间和跟随 | 已看 167.8–168.74 秒与 170.8–171.74 秒的 15fps 解码帧列；起身和命中阶段可读，但姿势间依赖少量原画，不能声称逐帧细密连续 |
| 镜头与效果 | 初版火焰排列僵硬、命中中心脱开、收势裁切已修改；最终背景可见破损石块和不均匀边缘，整体宫殿构图仍正面集中 |
| 声画 | 沿用原声，PCM 检查相关 0.999411、时偏 0 ms；仅数值与口型时点证据，未进行听觉复核 |
| 开放复查 | 最终两人全身、脚、盾、断扣和落地后状态可见。仍有有限动画的持姿感，不能把画风改善等同于完整动画质量通过 |

漏检学习：先前把命中与后仰画好后没有为落地独立安排收势画，造成动作终点停在
悬空形状；本轮复看完整尾段才发现。之后同类制作在计划关键画时纳入落地/卸力，
仍需看最终像素，不把“有一张落地素材”当作自动成立。
