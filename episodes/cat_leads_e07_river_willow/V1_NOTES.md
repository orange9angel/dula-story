# E07《柳树下的老钓友》制作笔记

> 长篇连载结构验证集：新人物逐步登场（小橘人脉结构）+ 伏笔首埋 +
> 环境微动语法（A/B 变体扩展到柳枝/光斑）。

## 剧情

午后，小橘带小蓝和阿澈去上游柳滩——钓鱼的老周（OldMan）是它的老相识。
垂钓闲谈，老周提到夜里河面发青光（F03），小橘望着后山出神（F02）。
签名句式：Cat「去见个老朋友。」呼应 E05「带你去见一个老朋友。」。

## 翻车与新发现

1. **cloudDrift 贴纸云**：程序化椭圆云叠在烘焙的绘画感云层上像贴纸——
   全部撤掉。纪律追加：程序化图层只允许出现在**纯平涂天空**上；有烘焙
   云的画面禁用。云层运动留给 A/B 变体语法。
2. I2V 上传偶发 write timeout（网络瞬断），gen_i2v_seedance.py 自带
   2 次重试不够用，脚本幂等直接重跑即可。
3. omni 槽加宽的级联又踩一次：改 omni 槽起点要同步保留同 at 的静态帧条目
   （cel 模式回退靠它），这次用脚本断言兜底了。

## V2 修复（导演复片反馈，2026-09-05 深夜）

1. **狐狸尾幻视（P0）**：omni shot01 prompt 里写了"视线落在猫身上"而底图
   没有猫 → OmniHuman 在角落幻觉出一条狐狸尾。纪律：**omni prompt 不得
   提及底图中不存在的事物**（模型会脑补）。去猫重 roll 修复。
2. **尾句配音**：导演听感"不太对"——「……没什么。」的省略号前缀让
   seed-tts 出怪腔。改文本为「没什么。」（停顿由 omni 前垫承担）重配。
   候选试听留档 tmp/cat_016_*.mp3。
3. **柳枝两帧交替太闪（strobe）**：A/B 双帧 1.05s 交替读作"闪烁"而非
   "摇摆"。修法：**加中间帧变三帧循环 A-mid-B-mid**（codex 双图编辑：
   "halfway between image 1 and image 2"），0.475s 步进。
   光斑中间帧因 codex 配额耗尽未生成（23:03 后重置可补），结尾仍 A/B。
4. **表演密度失衡分析**（导演问"老人为何超过主角"）：老周 5 个近景 omni +
   慢语速 + 皱纹脸信息量大；主角大量台词是 VO/短镜。纪律：**主角台词不省
   近景**——VO 省成本但丢表演存在感，E08 起主角表情密度补齐。

## V3 修复（导演复片第二轮，2026-09-05 深夜）

1. **10-13s 色变根因（双层）**：frame_05 关键帧本身就是树荫场景（比邻镜
   暗 25%）+ Seedance 满血版输出再暗一截（均值 [85,146,148]→[69,125,127]）。
   修法：cel 做 Reinhard 色板匹配，目标取 frame_04/frame_05 均值中点、
   保留 cel 自身对比度（tools/match_i2v_color.py）。纪律：**I2V 段入片前
   逐段比邻居均值，偏差 >10% 就做色板匹配**；首帧关键帧本身要和相邻镜头
   同亮度档。
2. **暗线氛围定调（导演）**：本剧暗线是"高阶智能降临"的敬畏感——干净、
   明亮、超越——不是鬼片恐怖。老周神秘段 omni prompt 从"眉头微蹙/神秘"
   改为"眼神清亮笃定、讲述美好事物、毫无阴霾"。台词同步改：
   「夜里的河面会发光。青色的。」「那光很干净。」——伏笔词从"青光"
   变为"干净的青色光"。
3. **老周台词去油气**：删掉"喽/啦/哟"句尾语气词和"老喽眼花"式自嘲，
   全部改短句平叙（「小橘。带朋友来了。」「老相识了。这条河，它比我熟。」
   「一闪一闪。也许是我眼花了。」）。纪律：长者/智者角色慎用语气词。
   四句全部改挂 calm（tenderness 偏腻）。

## V5（导演复片第三轮，2026-09-05 深夜）

1. **环境镜头动起来**：开场 establishing 改 I2V（柳枝摆+河面流，无人物——
   I2V 合法区），15s 入场段改 I2V（少女走入+抬头看柳）。规则确认：
   **无角色的空镜/大环境运动是 I2V 的最佳用法**，比静态帧+叠层生动且零风险。
2. **台词二修**：鱼竿问答改「用了很多年了吧？」/「这鱼竿已经用了三十年了。」；

3. **结尾去恐怖套路**：F02 静帧保留，但台词改成向往式——小蓝「你在看什么
   呀？」、小橘「下次，带你去个更漂亮的地方。」（同一画面从"回避"变"约定"，

## V9（导演复片：向往语法定调，2026-09-06）

1. **基调裁决（导演）**：青光段和结尾猫帧读出了"悬疑/不舒服"，与本剧"阳光、
   温暖、高阶文明"基调冲突。根因不是暗线元素，而是**呈现语法借自恐怖片**：
   老人压声转述、孩子不安对视、猫回避+警觉表情、留白当悬念。
   定调升级为**向往语法**：信息差保留，每拍情绪符号为正（渴望而非害怕）。
   纪律全文写入 docs/cat_leads_series_bible.md 2.0 节。
2. **三帧 prompt 修正**（tools/gen_seg2.sh，旧帧备份 tmp/old_frames_v8/）：
   - frame_19：孩子对视困惑 → 眼睛发亮、惊叹向往（"想看！"的能量）
   - frame_21（F02）：删掉 "unnaturally focused / tail wrapped tight" →
     放松眷恋，"像猫看初雪、像看老朋友的家"
   - frame_23（结尾回头）：删掉 "deliberately neutral / as if nothing
     happened"（回避语法，成片读作警惕）→ 半阖眼温柔眷恋、安静告别心爱的风景
3. **老周定位修正**：暗线的守护者而非证人——河里的光是他的老朋友，
   「这条河，它比我熟」在此解读下成立，为交汇集回收预留重估接口。
4. 纪律回写：story-writer/references/directing-craft.md（信息不对称一节加
   情绪符号规则）、series-architect SKILL.md（核心规则加向往条款）。

## V10（omni 丢失事故修复，2026-09-06）

1. **事故**：V9 重渲染后导演发现"老爷爷动作全没了，变成静态图片"。根因：
   重建时间轴时跑了 `python tools/build_timeline.py`（默认 `--mode cel`），
   9 个 omni 说话镜头全部回退成静态关键帧。
2. **修复**：`--mode omni` 重建（504 entries / 399 omni cels）+ 重渲染，
   抽帧验证 19s/42s 同槽两帧嘴型不同（omni 运动确认）。
3. **根因治理**：build_timeline.py 默认模式改为 `omni`——脚本本来就有
   逐镜头回退（cels 缺失自动落静态），默认值不应该选择降级路径。
   纪律：**重建时间轴后必须抽 omni 槽内的两帧对比验证运动**，再进渲染。
