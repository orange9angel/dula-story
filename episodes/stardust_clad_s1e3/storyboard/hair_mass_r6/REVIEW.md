# 头发连贯色块与多角度试验 R6

本轮按用户提出的“整体色块”修改真实三维角色。左栏为上一轮 boundary R2，
右栏为本轮候选。两栏使用同一人物、脸、衣甲、机位、动作和光源；不是生成图，
也没有按相机方向切换不同发型。正式剧集没有被此试样替换。

## 已看到的收益

- 各网格共用暗底色，取消逐束体积阴影及内部边线，原来的叶片/胶块边界明显减轻。
- 耳后和后颈的下部色块接入主体，保留两侧耳朵；没有保留 R1 遮耳垂领的大壳。
- 侧面中段与末端一起向后组织，少量亮面交代弯曲；侧面不再只依赖圆形后脑。
- R5 转头时露出的额侧肤色夹缝，在 R6 的局部内衬修正后闭合；中央露额和眼睛保留。

这些是本轮局部收益，不表示整体已达到参考水平。

## 尚未解决

- 后脑仍偏整团，尖角与圆团的过渡偏硬，缺少参考图中的流畅轮廓节奏。
- 后颈下缘偏均匀锯齿；正后俯视时尤其明显。
- 部分亮面像短带，端口受遮挡切断，右侧面比左侧面更明显。
- 俯视时侧上方仍有极小背景缺口，需继续检查主束与冠部的衔接。
- 这段是头发专项，不包含行走、打斗、肉体、脸部表演及整集灯光验收。

## 多角度和时间证据

`preview/` 为 8 个水平视角，加正面/后脑各两个俯仰角。`decoded/` 从实际 MP4
解码，包含转头、反向、整周转台、侧面过渡、换光与俯仰。审查方式是静帧和
有序帧列，没有把它描述为原速视频观看，也没有完成与参考动作的同条件动态比较。

视频时间：

- 0–4 秒：头部独立转动、反向、停头及小幅俯仰。
- 4–8 秒：整人转台，仅用于看模型各面，不用来证明真实转身的头发惯性。
- 8–12 秒：主光变化；脸部仍沿用固定绘制光影。
- 12–16 秒：正面和后脑俯仰，14 秒切到背面属于诊断视角切换。

根部位移、非有限值、顺序/seek 一致性只验证渲染实现。
下部补片跟随头部，没有独立物理模拟；动态探针只覆盖 `parts` 中的活动发束。
R6 的 `unchangedScalp` 为 false 是有意的局部额侧覆盖修订，不是失败断言。
此数值即使为 true，也不能排除别的新增几何造成头套。

## 本轮中间版本

| 版本 | 实际结果 |
|---|---|
| R1 | 色块统一，但下部补壳过大遮耳、垂到领口，拒绝 |
| R2 | 缩回补壳、缩短鬓角；侧后过于空白 |
| R3 | 球面亮区像涂刷，梢端像圆团上的长针，拒绝 |
| R4 | 调整侧面中段及末端，恢复随形亮面；后侧翼角过大 |
| R5 | 缩小侧翼，导出后从转头帧列发现额侧露肤夹缝 |
| R6 | 局部修补额侧内衬；保留后脑形状、下缘和亮面问题 |

R1–R5 的 `source/` 保存当时修改的代码，`preview/` 保留失败图。
R5 还保留实际视频解码证据，不能在后续修订后改写成当时已经通过。
R6 的 `manifest.json`、`source_snapshot.zip` 和 `render/render_build.json`
记录交付来源及技术验证。完整巡检在 `../character_attention/hair_mass_r6.json`。

## 参考范围

用户上传图保存在 `../hair_fine_reference/user_reference.png`，只作暗色与亮面关系参考。
此前已查的公开多角度线稿和发行方彩色图，来源见
`../hair_reference_comparison/manifest.json`。这些不是同一角色的完整彩色三维设定，
不能据此宣称全角度精确还原。

本轮纠正的制作假设：细密感不必靠不断添加细束，先核对暗色是否连贯；
但统一颜色也不能替代侧后轮廓、发际线、耳颈留白和随形亮面。
