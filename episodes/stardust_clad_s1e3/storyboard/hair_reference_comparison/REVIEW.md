## 看到的区别

| 部位 | 参考图中的可见关系 | 我们原版与 R6 的问题 |
|---|---|---|
| 近正面 | 刘海在大形中聚拢，弯曲后分成宽窄、长短不同的尖端；额前空隙是发束之间的形 | 原版额前露出一块连贯的底壳，厚束像压在壳上。R6 露出了额头，但中段贴头，末端又过细，部分像贴条 |
| 斜侧 | 主束有从头顶向侧后展开的大弧，细束依附主流向；外轮廓长短和间隔有节奏 | 原版多条圆滑粗束各自成立，整团缺少主次。R6 的细尖从圆形主体突然伸出，根部到末端的宽度和方向不连贯 |
| 侧面 | 前额蓬起、耳前鬓束、耳后发量、后颈短束分工可读；外轮廓不是颅骨的平行线 | 原版后脑是一组近乎平行的厚条；R6 后脑仍像罩壳，耳后大片直接垂下，顶部细翘束没有形成中段体积 |
| 后斜面 | B 的外轮廓向两侧展开，再在颈后分短束收回；内部线少，轮廓仍说明发量 | 两版主要沿圆壳排纵条。R6 只在边缘和顶部添细尖，主体没有得到相应的方向变化；存在细缝与碎边 |
| 明暗 | C 中暗部可以连成一大块，亮面在主束上弯曲、变窄，留出明确的暗缝；不是每束都画同样的反光 | 原版每束圆滑亮条强调管状厚度。R6 降低了圆管感，但侧后横带跨过多束，另一大片暗面仍按圆壳切分，没有充分说明发束交叠 |

判断是：两版在这些已查看关系上都明显弱于参考；R6 有“去掉管状亮纹”的局部收益，
但没有形成整体升级。短发不必变成参考的蓬松长发，也不必复制其特征性剪影；
需要迁移的是主次、发流、收束和亮暗的组织方法。

## 代码追因：与观察分开

1. `dula-assets/characters/stardust/layered-hair.js:16` 使用头部椭球径向量构造
   `hairForm`，不是各主束的实际弯曲面。它可以统一光照，却也会强化圆壳读感。
2. 同文件第23行按 `hairLocal.y` 的固定区间生成亮带，横跨不同束面。
   这与 5.0、6.5 秒实际可见的横亮带相符。问题不是“亮带都不允许”，
   而是这条带没有被发束方向、遮挡和局部起伏组织。
3. `wrap()` 把根部和大部分中段投回同一椭球，只让后段脱离。结合当前设计，
   这解释了主体贴头、末端突然伸出的趋势；应由有设计的主束面来验证替代方案。
4. 原版 `soft-portrait.js:24` 为圆截面发束计算逐束明暗、sheen 和周期细亮纹，
   对应原版粗管/胶条观感。
5. 两版头发都有独立写定的光向，当前实现没有从场景主灯或剧情光效取得方向。
   这是已确认的实现限制；本轮未改变灯位渲染，所以不把它写成已经实测的灯光跟随故障。

## 后续修法与验收依据

先形成属于本角色的正、斜、侧、后设计，明确主束方向、中段离颅距离和耳后/颈后
收束，之后再匹配网格。单纯加尖端、改色阶或增加发片数量不是这次问题的修法。

明暗需要同时保有整团大关系和主束转折：先去掉无依据的等高亮带，再用主束亮面、
交叠暗边和可控的场景主光关系试样；“整体明暗”不能退化成给所有束统一球面法线。
用同机位原版/候选比较轮廓、纯色形、明暗与完整头像，再看转头前后过程。

动态暂不判优劣：仍需匹配转头、停头、风向的参考连续片段，检查根部锚定、中段
带动、末端滞后和恢复。当前 R6 的速度驱动末端偏移不等于已完成这些动作设计。
本轮也没有评价脸、肉体、走路、打斗或音频的改进。
