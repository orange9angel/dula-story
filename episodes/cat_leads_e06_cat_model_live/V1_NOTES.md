## 下周计划：世界统一实验（导演定案 v3，总预算 ≤¥60）

**第 1 步 · 设计方向（¥0，可选）**：codex 静帧仅作方向参考（构图/服装/
气质讨论），不当生产规格——真人脸图片过不了 Seedance 审核墙，定了也
进不去。场景静帧（无脸）可定稿后直接作 I2V 首帧。

**第 2 步 · 内部定稿（~¥7–12/角色，导演 2026-09-06 简化+成本优化）**：
不定外部静帧。两阶段抽卡：① 文生图初筛（~¥0–2，Seedream/即梦与
Seedance 同宗，方向近似，毙掉脸型/气质/服装不对的方向）→ ② 仅决赛
方向的 prompt 进 T2V（~¥5.24/roll ×1–2，脸在模型内部出生、天然过审），
监制在候选视频中挑脸定稿——定稿视频本身就是生产锚点，直接进视频参考链。
注意：图片筛的是"方向"，视频长出的才是"脸"，最终验收永远在视频。
控制方式为"候选挑选 + prompt 微调逼近"（服装/发型/气质写进 prompt），
非"像素级精确设计"。**C（DA 驱动外部定稿静帧）降为特种通道**——仅在
需要某张特定的脸（如保住 V1 角色）时启用，选 C 而非换脸的理由：与全
管线同为云 API、DA 保整头（发际线/头型/背景一体）；B（facefusion）
继续兜底。纹理纪律：全部镜头走视频模型生成（环境镜若 2.0/2.5 纹理差
肉眼可辨则统一 2.5）；对齐用音频加垫，禁视频变速。

**第 3 步 · 6 秒稳定性实验（≤¥30）**——橘猫 2s 不说话 → 2s 说话 →
2s 再不说话：

- **V-a 单段 6s**：Seedance 2.5 一次生成，音频参考只含中间 2s 台词。
  验证单段内"只在语音区动嘴 + 前后静默段身份/场景零漂移"（≈¥10–15）。
- **V-b 三段拼接**：2s I2V（静默）→ 2s 视频参考链（说话）→ 2s I2V（续帧）。
  验证跨段接缝连续性（≈¥12–16）。
- 验收：全 6s 猫脸/花色/背景逐段 1-5 分；动嘴是否严格落在语音区；
  V-b 两个接缝逐帧对比；2.0 vs 2.5 单帧纹理并排比。通过后才谈全片重制。
- 执行纪律：先 V-a 确认锚点可行再放 V-b；TTS pad ≥1.8s；批次生成前
  先用一镜验证与本集既有素材一致再放全量。
