## 不能算验收通过的地方

1. **T2V 重新建角色造成换脸**：V2 男孩比 V1 的年龄感更小，女孩从有刘海变成中分长发。测试只说明新参考链内部有一定一致性，没有证明保留 V1 身份。s12/s17 的 V1 占位会使差别尤其明显。
2. **场景不是自动锁死**：女孩、猫参考建立镜和 V1 不是同一树干/石阶几何；男孩 s09 仍以大块石坡为背景。调色无法修复这些差异。
3. **替换音轨不等于口型同步**：生成语音在部分素材里延迟 1–3 秒开口、语速和停顿也变了。本次已做区间对齐，但仍需实时播放判断字内节奏、闭嘴时刻和变速后的表演是否自然。
4. **两句待生成**：32.5 秒「嗯，这样也挺好。」和 47.5 秒「这张最像它了。」。仅补齐两句不会解决前述角色/场景问题。后续付款前应先确定是否接受这组新角色，或改用现有 V1 视频作为原身份参考再验证。

因此不沿用先前“锁脸 5/5、锁景 5/5、问题结构性消灭”的定稿结论。

## 重建

仓库根目录：

```powershell
.\.venv\Scripts\python.exe episodes\cat_leads_e06_cat_model_live\tools\build_v2.py --preview
```

不带 `--preview` 时，只要还有 `pending` 镜头就拒绝输出定稿。新增镜头必须先更新 `config/v2_edit.json` 的实际对齐和审核状态；不能仅凭文件存在就当作验收通过。

另纠正交接中的型号说法：字节的 [Seedance 2.0 官方页面](https://seed.bytedance.com/en/seedance2_0) 明确列出图片、音频和视频参考能力，“2.0 全系没有音频参考”不成立。具体账户/API 能否调用仍应实测，不应从脚本缺少参数反推整个模型不支持。
