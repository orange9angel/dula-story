# 《殖装学园》系列圣经 (SERIES BIBLE)

> 活体漫画长篇 · 热血生物机械校园剧
> 类型定位：生物机械殖装（活体装甲、单元、兽化）× 校园社团流派对决（社团战、殖装武装、冷面宿敌）。
> 本文件是全部剧集的最高设定锁：角色花名册、力量体系、社团编制、长篇弧线。
> 各集的 `STYLE_BIBLE.md` 管画面，`script.story` 管时序，本文件管「世界是否自洽」。

## 1. 世界观

**青岚学舍**，山城学府，以「武斗社团」闻名——刀术部、拳斗部、摔跤部、田径部（疾走流）各有百年传承，社团之间的单挑传统被称为**「社团战」(Club War)**。（平行世界：架空地名与服饰，不可读出具体国家与年代。）

三个月前，一颗「陨石」坠入后山。那不是石头，是外星生物科技的货柜，里面装着**殖装单元 (Bio-Unit)**——活体装甲的种子。撞击把货柜震碎：一枚完整单元（零式）+ 十余枚**单元碎片 (Shard)** 散进校园。

被碎片附体的人获得局部生物机械武装（刀、拳、腿甲）；被完整单元选中的人，可以全身殖装。

于是古老的社团战复活了：赌注从锦旗变成了碎片。赢者吞噬输者的碎片，输家的武装被剥离——**剥离会带走宿主的一部分生命力**。校园地下秩序由此重写。

没有人知道：货柜是「投递」，不是「坠落」。收件人还没来。

## 2. 力量体系（硬规则，剧集不得违反）

| 概念 | 规则 |
|------|------|
| **殖装单元 (Unit)** | 活体装甲种子，自主选择宿主，与宿主神经共生。唯一完整单元 = **零式**，宿主雷晓。 |
| **殖装核 (Core)** | 胸口生物核心，单元的本体。核不灭，殖装可无限再生；核碎，宿主死。 |
| **单元碎片 (Shard)** | 不完整单元，只能武装单一器官/武器。可移植、可剥夺。 |
| **殖装展开** | 本能先于意志：宿主濒死/受袭时单元自动防御（第 1 集核心桥段）。熟练后可意志驱动。 |
| **蚀 (Corrosion)** | 过度使用殖装，生物质向宿主身体蔓延（黑色血管状纹路）。蚀过心口者，不再是人。——长篇主悬念。 |
| **社团战 (Club War)** | 放学后、**西岸废工地**（城市边缘的废弃建筑工地，社团战的百年决斗场）、一对一、赌注为碎片。被选中者**无权退场**（第 1 集白岚宣告的规则）。校园只是日常的面具，战斗永远发生在校外——废工地、河岸、后山坠坑、乃至外星人基地。 |
| **观察者 (The Observer)** | 不参战、不结盟，记录每一场社团战。真实身份是长篇暗线。 |

**战力标尺**：碎片持有者（局部武装）＜ 完整单元（全身殖装）＜ 蚀化者（非人化，后期敌役）。

## 3. 角色花名册

### 主角

**雷晓 (LeiXiao)** —— 高二，回家部（无社团）。怕事、自嘲、想平凡。三天前在后山被「零式」选中。
- 殖装形态：**零式装甲**——黑铁色生物质甲壳、圆润肩甲、右前臂可展开**殖装刃**、胸口青色发光殖装核（#3DFFC8）。
- 盲点：以为躲就能脱身。弧线：被迫应战 → 主动守护 → 直面「蚀」的代价。
- 声线：少年音，平时虚、慌，爆发时破音嘶吼。

### 第 1 集对手

**白岚 (BaiLan)** —— 刀术部部长，冷面规则化身。欧系长相青年教头气质：灰金色散发松束、短髯、左眉至脸颊一道旧疤。碎片「刀蝉」附体其直刀，刀身被灰白生物组织包裹，即**细胞刀**。着世界混搭武者装：深靛交领长袍 + 旧皮束带 + 单边旧铁肩甲（架空、无年代国籍特征）。
- 不是恶人：他是社团战秩序的守门人，先礼后兵，认可对手后会收刀。
- 声线：低沉、短句、不容置疑。
- 弧线定位：第一集的对手 → 后期的战友（宿敌转正）。

### 旁白

**Narrator** —— 画外音，只出现在每集首尾，负责「漫画旁白框」式的压缩与钩子。声线：成熟男声，说书人腔。

## 4. 长篇弧线（Season 1 骨架）

1. **E01《选中者》**：雷晓被白岚逼战，零式自动防御暴露——全校皆知。（本 pilot）
2. **E02-E03**：拳斗部轰刚登门。雷晓第一次意志驱动殖装，惨胜；左臂出现第一道「蚀」纹。
3. **E04-E06**：生物部千堂葵介入，揭示碎片可剥夺、剥离伤命；雷晓为救败者而战，第一次主动使用殖装。
4. **E07-E09**：学生会长的「碎片狩猎」浮出水面；白岚败于会长、被剥夺「刀蝉」，宿敌转正。
5. **E10-E12**：蚀化者出现（过度使用的前辈）；零式的真正来历——货柜是投递；观察者亮明身份。季终钩：后山货柜再次发光，「收件人」到达。

## 5. 每集结构模板（pilot 已按此执行）

1. 冷开场：日常一格，迅速被异常打破。
2. 规则宣告：本集对手登场，社团战规则经由冲突讲清（不做说明书）。
3. 升级：拒绝/逃避 → 被迫出手。
4. 不可逆转折：殖装暴露/新代价出现。
5. 收刀与钩子：对手留话退场 + 旁白一格收束，留下一集悬念。

## 6. 活体漫画格式锁（全系列统一）

- **画面即漫画格**：每帧按漫画大格构图，网点、墨线、纸纹常驻（见 STYLE_BIBLE.md）。
- **气泡字幕**：对白用漫画气泡（尾巴指向说话者），不用底部字幕条。
- **拟声词大字**：打击/变身/冲击格配手写体拟声词（「铛——！」「轰！」），叠加在画面上层。
- **翻页转场**：场景/段落切换用翻页（page turn），不用 Fade；镜头内切换用硬切（cut），收尾空镜可用 crossfade。
- **冲击帧**：命中瞬间 1-2 帧黑白反转 + 高对比（impact frame），少年漫标准语法。
- **集中线/速度线**：动作格与特写格按 shot 配置程序化叠加。
- 嘴部/眨眼 cel 动画：局部编辑 + 羽化锁回（rig 只贴 rect，漂移不进正片）。
