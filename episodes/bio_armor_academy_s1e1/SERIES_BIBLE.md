# 《9章》系列圣经 (SERIES BIBLE)

> 活体漫画长篇 · 热血生物机械校园剧
> 类型定位：生物机械殖装（活体装甲、单元、兽化）× 校园社团流派对决（社团战、殖装武装、冷面宿敌）。
> 本文件是全部剧集的最高设定锁：角色花名册、力量体系、社团编制、长篇弧线。
> 各集的 `STYLE_BIBLE.md` 管画面，`script.story` 管时序，本文件管「世界是否自洽」。

---

## 1. 世界观

**青岚学舍**，山城学府，以「武斗社团」闻名——刀术部、拳斗部、摔跤部、田径部（疾走流）各有百年传承，社团之间的单挑传统被称为**「社团战」(Club War)**。（平行世界：架空地名与服饰，不可读出具体国家与年代。）

三个月前，一颗「陨石」坠入后山。那不是石头，是外星生物科技的货柜——一座**基因火种库**，里面装着**殖装单元 (Bio-Unit)**：活的基因种子。撞击把货柜震碎：一枚完整单元（9章）+ 十余枚**单元碎片 (Shard)** 散进校园。

单元落地后做的第一件事，是读取地球的基因库。它跳过了哺乳动物，选中了**昆虫**——地球上迭代了四亿年的终极战斗设计：外骨骼、复眼、膜翅、捕捉足、共振器官。殖装不是穿在身上的装甲，而是昆虫特征**从宿主的骨骼和皮肤里长出来**。

被碎片附体的人，局部表达单一昆虫器官（蝉翼、甲壳、毒针）；被完整单元选中的人，可以全身虫化殖装。

于是古老的社团战复活了：赌注从锦旗变成了碎片。赢者吞噬输者的碎片，输家的武装被剥离——**剥离会带走宿主的一部分生命力**。校园地下秩序由此重写。

没有人知道：货柜是「投递」，不是「坠落」。收件人还没来。

## 2. 力量体系（硬规则，剧集不得违反）

| 概念 | 规则 |
|------|------|
| **殖装单元 (Unit)** | 外星基因火种，以昆虫为表达模板，与宿主神经共生。虫的特征从骨骼里长出来，不是穿戴。唯一完整单元 = **9章**，宿主雷晓。 |
| **9章（未分化原型）** | 唯一**尚未选定昆虫模板**的单元。名字来自学舍档案：货柜里寻获的寄宿文档只剩残卷**第九章**，前八章全部散佚——没人知道它的全名与来历，只好以「9章」称之。（前八章的下落 = 长篇暗线，与「收件人」挂钩。）它随宿主的战斗与情绪极限逐步表达新特征（复眼→膜翅→捕捉足……），每次进化称为一次「羽化」。它选中雷晓，正因为雷晓是「还没定型」的人——一张白纸配一颗未定型的种子。长篇核心悬念：9章最终会成为什么虫，由雷晓的选择决定。 |
| **殖装核 (Core)** | 胸口生物核心，单元的本体，气管状光路（#3DFFC8）由此蔓延全身。核不灭，殖装可无限再生；核碎，宿主死。 |
| **单元碎片 (Shard)** | 只携带单一昆虫模板，只能表达单一器官（蝉翼刃、拳甲、腿甲）。可移植、可剥夺。 |
| **殖装展开 / 初羽** | 本能先于意志：宿主濒死/受袭时外骨骼与鞘翅自动张开（第 1 集核心桥段）。熟练后可意志驱动。 |
| **蚀 (Corrosion)** | 基因过度表达：虫的特征不可逆地侵占人体——复眼、附肢、外骨骼取代人的部分。蚀过心口者，不再是人——**字面意义上变成虫**。——长篇主悬念。 |
| **社团战 (Club War)** | 放学后、**西岸废工地**（城市边缘的废弃建筑工地，社团战的百年决斗场）、一对一、赌注为碎片。被选中者**无权退场**（第 1 集白岚宣告的规则）。校园只是日常的面具，战斗永远发生在校外——废工地、河岸、后山坠坑、乃至外星人基地。 |
| **观察者 (The Observer)** | 不参战、不结盟，记录每一场社团战。真实身份是长篇暗线。 |

**战力标尺**：碎片持有者（单一虫器官）＜ 完整单元（全身殖装+持续羽化）＜ 蚀化者（半人半虫，后期敌役）。

## 3. 角色花名册

### 主角

**雷晓 (LeiXiao)** —— 高二，回家部（无社团）。怕事、自嘲、想平凡。三天前在后山被「9章」选中。
- 殖装形态（E01 初羽）：右前臂被**黑亮几丁质**覆盖，甲虫腹节般的分节甲壳，关节处有半透明薄膜，指节分节化；受击瞬间前臂弹开**鞘翅状骨板**成盾；胸口殖装核（#3DFFC8）的光沿气管状接缝蔓延。他还不会任何招式——9章替他还手。
- 9章是未分化原型：它还不知道自己是什么虫。雷晓的每次抉择，都在替它投票。
- 盲点：以为躲就能脱身。弧线：被迫应战 → 主动守护 → 直面「蚀」的代价（虫化）。
- 声线：少年音，平时虚、慌，爆发时破音嘶吼。

### 第 1 集对手

**白岚 (BaiLan)** —— 刀术部部长，冷面规则化身。欧系长相青年教头气质：灰金色散发松束、短髯、左眉至脸颊一道旧疤。**刀术部部长，早已不用刀**：碎片「鸣蝉」生于他的右前臂——一片琥珀色半透明**蝉翼**自前臂展开，翅脉是发光的生物回路，高频振动时即为共振刃。着世界混搭武者装：深靛交领长袍 + 旧皮束带 + 单边旧铁肩甲（架空、无年代国籍特征）。
- 招式：**「鸣切」**——蝉翼高频振动斩，先闻其声（一声蝉鸣般的刀鸣），后见其光；**「一寸鸣」**——贴身把共振直接打进对方骨骼。
- 蝉的意象：蛰伏十七年，只鸣一夏。他的忍与守序，都收在那片薄翼里。
- 不是恶人：他是社团战秩序的守门人，先礼后兵，认可对手后会收翼。
- 声线：低沉、短句、不容置疑。
- 弧线定位：第一集的对手 → 后期的战友（宿敌转正）。

### 旁白

**Narrator** —— 画外音，只出现在每集首尾，负责「漫画旁白框」式的压缩与钩子。声线：成熟男声，说书人腔。（E01 火山图生视频版**不设旁白**，收尾靠空镜 + 音效。）

## 4. 长篇弧线（Season 1 骨架）

1. **E01《选中者》**：雷晓被白岚逼战，9章自动防御暴露——全校皆知。（本 pilot）
2. **E02-E03**：拳斗部轰刚登门。雷晓第一次意志驱动殖装，惨胜；左臂出现第一道「蚀」纹。
3. **E04-E06**：生物部千堂葵介入，揭示碎片可剥夺、剥离伤命；雷晓为救败者而战，第一次主动使用殖装。
4. **E07-E09**：学生会长的「碎片狩猎」浮出水面；白岚败于会长、被剥夺「刀蝉」，宿敌转正。
5. **E10-E12**：蚀化者出现（过度使用的前辈）；9章的真正来历——货柜是投递；观察者亮明身份。季终钩：后山货柜再次发光，「收件人」到达。

## 5. 每集结构模板（pilot 已按此执行）

1. 冷开场：日常一格，迅速被异常打破。
2. 规则宣告：本集对手登场，社团战规则经由冲突讲清（不做说明书）。
3. 升级：拒绝/逃避 → 被迫出手。
4. 不可逆转折：殖装暴露/新代价出现。
5. 收刀与钩子：对手留话退场 + 旁白一格收束，留下一集悬念。

## 6. 活体漫画格式锁（全系列统一）

- **画面即漫画格**：每帧按漫画大格构图，网点、墨线、纸纹常驻（见 STYLE_BIBLE.md）。
- **气泡字幕**：对白用漫画气泡（尾巴指向说话者），不用底部字幕条。
- **拟声词大字**：打击/变身/冲击格配手写体拟声词（「铛——！」「轰！」），叠加在画面上层。
- **翻页转场**：场景/段落切换用翻页（page turn），不用 Fade；镜头内切换用硬切（cut），收尾空镜可用 crossfade。
- **冲击帧**：命中瞬间 1-2 帧黑白反转 + 高对比（impact frame），少年漫标准语法。
- **集中线/速度线**：动作格与特写格按 shot 配置程序化叠加。
- 嘴部/眨眼 cel 动画：局部编辑 + 羽化锁回（rig 只贴 rect，漂移不进正片）。
