# 《伞下晴天》分镜方案

## 创作目标

- 片长：128.5 秒，直接发生在古代江南，不展示穿越过程。
- 情感：小蓝主动、机灵、敢想；阿澈腼腆但会接话。爱情来自共同完成一件事，不靠误会或苦情。
- 视觉：原创“新工笔电影动画”——青绿山水的青蓝、朱砂点色、矿物金粉、绢本细纹，与现代电影式冷暖光和湿地反射结合。禁止统一复古黄滤镜。
- 动态：动作 beat 用密集关键帧；风卷伞追逐、开伞、雨势变化、衣袖与发丝、滴水、涟漪、花瓣和破云光束共同制造运动。

## 角色与服装锁定

- 小蓝：保留现代版的深靛蓝长发、琥珀金眼、清秀圆润脸型。明制汉服风格，月白交领右衽上衣，青黛马面裙，朱砂窄边，深蓝发带和一枚小金簪；动作利落，不是柔弱闺秀。
- 阿澈：保留现代版黑发、温和眉眼和少年感。宋制青年画师，米白交领右衽长衫、青灰外褙、靛蓝腰带，半束发玉簪；不留胡须，不做老成书生。
- 道具：一把旧的深靛蓝油纸伞，外侧素净，内侧逐渐出现一轮手绘矿物金太阳。全片只有这一把主伞。

## 镜头节拍

| 时间 | 画面与动作 | 动态/特效 |
|---|---|---|
| 0–12s | 清晨水巷、廊桥、画摊；小蓝抱破伞穿过薄雾走来 | 前景柳叶、花瓣、炊烟、水面微波、柔和侧逆光 |
| 12–28s | 小蓝把破伞递给阿澈，要他在伞内画太阳；两人第一次对视 | 递伞分三相位；近景眼神和手部；冷青背景对金色眼睛 |
| 28–46s | 翻伞、磨金粉、落笔；两人隔着伞沿斗嘴 | 金粉微粒、笔尖特写、衣袖与发丝小动作、表情反应切镜 |
| 46–65.5s | 阵风卷走伞；两人沿石桥追赶，阿澈抓住伞却也抓住小蓝袖子 | 追逐用接触/腾步/伸手/抓取/恢复多相位关键帧，快速横移与落叶 |
| 65.5–83s | 骤雨落下；阿澈护金粉，小蓝开伞，两人挤入伞下 | 远雷、雨线、石板涟漪、伞骨滴水、开伞三相位、冷蓝环境 |
| 83–100.5s | 伞内金太阳映亮两张脸；漏雨斗嘴，二人沿河慢走 | 金色反射、近景呼吸微动、雨线前后景分层、水花 |
| 100.5–116s | 雨势减弱，云隙阳光落在湿街；阿澈把功劳让给小蓝 | 雨逐渐稀疏、破云光束、湿地金色倒影、花瓣重新出现 |
| 116–128.5s | 小蓝约他明天再画；结尾远景，两人共伞停在桥心 | 手与伞柄特写、害羞反应、横卷式拉远，最后留环境音与余光 |

## 关键帧密度

- 约 38–44 个主关键帧。
- 风卷伞追逐额外 6–8 个动作相位，0.35–0.65 秒切换。
- 开伞额外 3 个相位；同伞靠近额外 2 个反应相位。
- 其余镜头 2.4–4.0 秒，通过推拉摇移、眨眼、口型、发丝/花瓣/雨线保持活性。

## 中式元素禁区

- 禁止和服、腰封式大蝴蝶结、鸟居、神社、木屐、武士刀、日式町屋招牌。
- 建筑使用白墙黛瓦、穿斗木构、石拱桥、临水廊桥、中文小篆/隶书风格摊牌（避免可读乱码）。
- 服装必须交领右衽，避免左衽；发饰与鞋履为中式。
