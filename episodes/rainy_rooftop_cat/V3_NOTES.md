# 《雨后天台》V3 晨报（2026-07-27）

## 针对的批评（V2 成片观感）

1. 「下雨没有动态」——实际是**观感问题而非渲染问题**：V2 的程序化雨丝层在动，但只有
   alpha 0.3 / 1.3px 的细线，被关键帧里烘焙的高对比静态雨丝完全压住，眼睛追踪不到运动。
2. 「水滴没有动态」——属实：frame_11 伞沿水珠特写的水珠画死在图里，无任何滴落动画。
3. 「说话、表情、动作不连续」——有限动画管线的结构性问题：每镜头一张静态图挂 1.5–3.5s，
   口型只有三态贴图，无眨眼、无表情变化；且有两段对白/SFX 前半程落在无 rig 的镜头上。
4. 「图片太少，至少 1 帧/秒」——独立图 24 张/31s，对白段一张图挂近 2s。

## V3 改动

### 程序化（scenes/RainyRooftopSequenceScene.js，零新图）

- **雨丝双层视差**：远景层 520 条细丝（同 V2 观感）+ 近景层 90 条粗亮丝（2.3px、alpha 0.55、
  34–58px 长、1800–2500px/s）。近景层是对比度主导，肉眼明确追踪到雨在动。
- **风阵风摆**：雨丝斜率随时间 ±0.07 缓慢摆动，雨向不再机械。
- **地面溅落冠**：26 个 deterministic 溅落点（0.24–0.36s 快循环短亮线），地面读得出「被雨砸」。
- **伞沿/伞骨滴水动画**：新增 per-shot `drips` 配置（发射点 + 水面线 + 周期），
  生长→坠落→溅圈三段循环，画在源图空间（随镜头 crop 移动）。
  - frame_11（21.2–22.6s）：伞骨 3 个发射点
  - frame_12（22.6–24.8s）：彩虹全景伞沿 2 个发射点，与 water_drip SFX 同步
- **猫发抖**：timeline `shiver: true` 给 frame_03 / frame_04，双正弦 1–2px 高频 crop 抖动。
