# W2 实验：6s 说话段背景一致性（帧链无缝拼接）

> 针对 V1/V2 验收暴露的问题：OmniHuman 说话段的背景与 I2V 实拍背景不一致
>（数字人背景=底图，底图与相邻镜头不是同一帧）。本周目标：**让人说话时的
> 背景和不说话时一致**。

## 假设

OmniHuman 的背景完全由底图决定（live-action.md 通道地图）。若把 omni 底图
换成**前一段 I2V 在切换点的最后一帧**，并让后一段 I2V 从 **omni 的最后一帧**
起步，则三段在像素层面共享锚点帧，接缝应不可见。

## 设计（6s = 2 + 2 + 2）

| 段 | 时间 | 通道 | 内容 |
|---|---|---|---|
| segA | 0.0–2.0 | Seedance 2.0 I2V（4s 截 2s） | 正脸中近景，抿嘴微笑不说话，仅发丝/呼吸微动；首帧复用 omni_base.png（¥0） |
| segB | 2.0–4.0 | OmniHuman 1.5 | 底图 = segA 在 t=2.0 的末帧；音频 = vo2 裁 2.0s（语音 0.28–1.09s），说「就待一会儿。」 |
| segC | 4.0–6.0 | Seedance 2.0 I2V（4s 截 2s） | 首帧 = segB 末帧（归一化回 1280×720），恢复静默微动 |

- 三段同机位同构图，检验切换点（2.0s / 4.0s）双侧帧是否无缝
- 脚本：`tools/gen_w2_seamless.sh`（幂等，存在即跳过）
- 产出：`output/w2_seamless_6s.mp4`，接缝检查帧在 `tmp/w2_accept/`

## 管线修订（制作中决议，2026-09-11）

原设计 segA/segC 走 Seedance I2V。segA 首帧（omni_base.png 正脸）被 Ark
审核拦截（`InputImageSensitiveContentDetected.PrivacyInformation`，与 V1
seg3 相同）。**结论复验：I2V 首帧含正脸即拒，同机位"静默-说话-静默"
三明治无法混排 I2V**。改为三段全部走 OmniHuman 帧链（segA/segC 用 2s
静音音轨，seg3 上周已验证静音驱动可行）。

## 验收记录（2026-09-11 出片）

- **成品**：`output/w2_seamless_6s.mp4` — 5.914s，1280×720，30fps，
  h264 + aac 192k。三段 OmniHuman 帧链：segA(静音2s) → segB(VO2「就待
  一会儿。」2s) → segC(静音2s)。
- **接缝目检（核心结论）**：两个切换点（2.0s / 4.0s）双侧各取 3 帧
  （tmp/w2_accept/seam_*.jpg）——太阳位置、水面碎金分布、远桥剪影、
  左侧草丛、女孩发型/脸/衣领全部连续，**色温零跳变，接缝不可见**。
  帧链底图方案成立：说话时背景 = 不说话时背景。
- **口型**：segB 内 2.35s 微张露齿 / 2.70s 圆唇 / 3.00s 大张，开合差异
  明确；接缝两侧帧（1.98s、3.98s）均为闭口微笑，无"带着说话的嘴切走"。
- **音频**：语音恰落在 2.25–3.06s（中段窗口），窗外静音；无双重发声。
- **blackdetect**：全片无黑帧。
- **成本决算**：OmniHuman ×3 段 ≈ ¥6–9（刊例待核）；I2V 2 次审核拒绝
  未计费；TTS/底图复用 ¥0。**合计 ≈ ¥6–9**。
- **工程教训**：① OmniHuman 输出 mp4 用 `ffmpeg -sseof` 取末帧会空输出，
  改 `-ss <dur-0.1>`；② `$(tos_url ...)` 命令替换里的 `exit` 只退出子
  shell，URL 必须判空（本次 segB 曾因空 URL 提交失败一次，未计费）。

## 抖动修复（2026-09-11 复审）

初审后观感"画面抖动"，帧间差分曲线定位出两个来源：

1. **25→30fps 重复帧 judder（主因）**：OmniHuman 输出 25fps，v1 拼接强制
   `fps=30`，每 5 帧重复 1 帧（差分曲线呈 0.2s 周期归零），播放即规律性
   卡顿。**修复：全链保持原生 25fps，不做 fps 转换。**
2. **接缝姿态跳变**：A 末帧 → B 首帧差分 4.0（段内基线 0.7 的 ~6 倍）——
   底图相同但生成起点有微小姿态差。**修复：两个接缝加 0.16s（4 帧）
   xfade 淡入淡出**（语音在 segB 内 0.28s 才起，淡变窗口不碰语音）。

修复后成品：`output/w2_seamless_6s_v2.mp4` — 5.59s，1280×720@25fps。
复检差分曲线：周期归零消失（无 judder），接缝尖峰 4.0 → 摊平为 ~2–3
的 4 帧缓坡；段内基线 A=0.73 / C=1.13（水面碎金+发丝的自然运动）。
v1（硬切 30fps 版）保留为 `output/w2_seamless_6s.mp4` 作对照。
**零生成成本**（纯 ffmpeg 重拼）。

## 清晰度修复（v3，2026-09-11 三审）

观感"说话时分辨率略模糊"。拉普拉斯方差量化（脸部裁剪区，越大越锐）：

| 方案 | segA | segB(说话) | segC |
|---|---|---|---|
| v2 帧链（底图=前段末帧） | 41.0 | 22.8 | 20.9 |
| v3 同源底图（三段同用 omni_base.png） | 41.0 | **34.4** | 41.6 |

帧链的**代际损失**是根因：segB 底图已是数字人渲染+压缩过一轮的帧，
每过一代锐度约腰斩。改**同源底图**（三段都从原始 omni_base.png 生成，
背景一致性仍由构造保证——输入图本来就是同一张），B 恢复 +51%，
C 完全回到一代锐度（B 剩余的差距是说话时嘴唇运动的动态模糊，正常）。

v3 两次重 roll 的教训（各 ¥2–3）：
1. prompt 提"对身旁的猫说话"→ OmniHuman 让一只**黑猫**在 2.5s 闯入画面
   右缘（废片保留 `assets/w2/segB_m_cat_intrusion.mp4`）。**omni prompt
   不得提及底图中不存在的生物**——上周纪律只约束"事物"，生物同样适用。
2. 说话段头部自然漂移（转向镜头），末帧姿态与底图差异大，导致接缝2
   xfade 出现**双重曝光鬼影**（废片 `segB_m_headturn.mp4`）。prompt 加
   "gaze fixed toward the right throughout / head stays in the exact same
   position / no turning toward the camera" 后，说话全程视线锁定、头位
   稳定，接缝淡变不可见。

**最终成品**：`output/w2_seamless_6s_v3.mp4` — 5.59s，1280×720@25fps。
三段同源底图 + 静音/语音轨 + 25fps 原生拼接 + 接缝 0.16s xfade。
目检：无猫、无鬼影、无 judder、背景/色温/人物全片一致，口型开合清晰。

## 结论与后续

**2+2+2 三明治可以无缝对接**，最终配方：**同源底图**（非帧链）+
静默段喂静音轨 + 说话段 prompt 锁视线锁头位 + 原生 25fps 拼接 +
接缝 0.16s xfade。代价：整段是数字人质感，不能享受 I2V 的环境运动
质量。若要对"纯风景段用 I2V、说话段插进来"的场景混排，正脸说话镜的
唯一过审通道是 Seedance 2.5 视频参考链（reference_video），留作下次
实验。
