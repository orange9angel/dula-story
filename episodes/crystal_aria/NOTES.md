## R2：人偶 → 少女肉体感（2026-10-30，用户：「身体还是人偶的感觉，没有肉体的感觉」；
「漫画层 3D to 2D 人偶到肉体感的处理，我们可能要重点做，这个非常重要」）

R1 人偶感的四个来源与 R2 做法（`hybrid/aria_pilot.js` `buildSoftBody` / `shade`）：
1. 硬圆柱拼接、关节硬接 → **平滑融合隐式曲面**（smooth-min，k=0.022）：髋顶、腰、胸廓、双胸、肩带/锁骨、斜方肌、颈、
   颅、面颊下颌、下巴、鼻、三角肌、上臂/前臂变径胶囊、掌、指；粒子撒在等值面上（6 次牛顿投影）。
2. 骨骼刚体 → **两骨线性蒙皮**：权重 = 各体块距离 exp(-d/9mm) 按骨累加取前两骨；静止姿 A-pose（FK 同一函数生成）。
3. 平涂亮度 → **逐粒子法线明暗**：月光左上前方；受光暖白肤色、背光冷紫（透光感）、轮廓光 0.32；背向镜头的粒子压到 0.1
   形成实心体积（additive 无深度时的可见性近似）。纱裙同样按径向法线着色。
4. 全身同材质 → **露肩胸衣**：领口线（中间微 V）以下孔雀绿衣料、领口金边，以上皮肤；头发改为 150 缕发丝从发际线梳向发髻。
另：颈缩短加粗（长细颈读成外星人）、肩头缩小（读成护肩）、眼窝挖洞删除。

踩坑：融合曲面在关节处外鼓约 k/4，「采样点在并集内 >4mm 就丢弃」把肘/腕附近的点全丢了，手臂断成平头方块。
用无光照调试（`?flat`）+ 沿肢体的粒子直方图（`window.debugArm`）定位为采样问题而非蒙皮；改为只在点深埋于**另一个**体块时丢弃。

产物：`output/aria_pilot_r2.mp4`（`config/aria_pilot_r2_pipeline.json`，19 项顺序/seek 一致），`storyboard/pilot_r2/`
（`sheet.png` 球内拼图、`upper.png` 上半身 2 倍裁区）。R1 保留作对比。
待用户确认后：把软体（隐式曲面采样 + 距离蒙皮 + 透光明暗 + 背向压暗）抽成共享运行模块，写回 cel-cinema / draw-over-animation

## R4–R5：抬臂连接处与肩部积木感（2026-10-30，用户：「胳膊抬起来，胳膊要和躯干连在一起，现在抬起来连接处是空的」
「胳膊上部和躯干连接的地方也还是能看出积木感」「五官和胳膊连接处的肉感细化一下就差不多了」）
- R4 根因：粒子在静止姿（A-pose）曲面上采样后只做蒙皮搬运，抬臂时原本藏在关节内侧、没采到粒子的「肉」露出 → 肩顶暗洞、腋下暗楔。
  修法：**逐帧在当前姿态的融合曲面上重新吸附**。每根骨记当前→静止逆变换，体块在各自骨的静止坐标里求值（posed SDF）；
  采样时为每粒子记 3.5cm 内的体块（≤10），只对跨骨粒子做 2 次牛顿投影，法线取当前曲面梯度。单帧 ≈3s（含页面加载）。
- R5 根因：肩是一根水平横杆 + 小球三角肌 + 直筒上臂 → 平肩直角。修法：斜方肌内外两段从颈根斜下到肩峰（外段挂锁骨骨）、
  锁骨、三角肌顺上臂拉长包住上三分之一、上臂收细、胸大肌边缘与背阔肌（腋前/后褶）；肩部体块单独融合半径 3–3.5cm（`bk`）。
- 五官：眼放大（小尺寸更好读）、睫毛线/瞳孔加深、眉加粗、鼻梁一线高光、唇线加深。全身镜头里仍只是隐约。
产物：`output/aria_pilot_r4.mp4`、`output/aria_pilot_r5.mp4`（各 19 项一致），`storyboard/pilot_r5/`。

## R6：锁骨与手臂连接处的「断开」（2026-10-30，用户截图：开场合手姿势，「胳膊和锁骨连接那块感觉还是断开的」）
无光照（`?flat`）证实几何连续，断开感来自光影：锁骨胶囊形成亮棱+其下暗沟读成接缝；三角肌与斜方肌末端之间的浅凹背光成暗带；
轮廓光把内部折痕描亮。修法：删锁骨硬棱；斜方肌外段延伸到肩峰外侧盖住上臂根（融合 4cm）；三角肌上移、融合 4.2cm；皮肤轮廓光 0.32→0.16。
经验：「看起来断开」先用无光照分清是几何还是明暗——后者要查硬棱、浅凹和轮廓光，而不是继续加体块。
产物：`output/aria_pilot_r6.mp4`（`config/aria_pilot_r6_pipeline.json`）。
