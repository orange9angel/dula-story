# E05《清晨速写》分镜表

系列：《猫带我去的地方》。工艺：晴印 sunprint 平涂（清晨变体，见 STYLE_BIBLE.md）。
总时长 60s，单场景 `MorningSketchScene`，canvas 1920×1080。

**本集是优化方案验证集**：I2V 走 Seedance 2.0 **满血版 1080p**（弃 mini 720p）；
关键帧 prompt 带表情分层描写；I2V prompt 带 L1 晨风布料/发丝动态词表；
OmniHuman prompt 带神态分层；Boy 声线换音色（弃 longshu_v3）。

角色：小蓝（Girl，沿用 E04）、小橘（Cat，沿用 E04）、阿澈（Boy，新登场，
设计锁沿用 xiaoju_secret，画风重绘为晴印）。

剧情：清晨六点，小橘一反常态早早在门口催小蓝出门，带她穿过挂着露珠的
小巷和石桥，来到河堤——转学生阿澈正坐在台阶上画速写，速写本里画满了
小橘。原来小橘每天清晨都溜出来陪他。小蓝撞破了"小橘的秘密"，阿澈腼腆
地展示速写本。结尾两人一猫并排坐在河堤台阶上，晨光把影子拉得很长。

## 验收要点（本集新增纪律）

- I2V 1080p：与静态 cel 并排放，剪辑点不得有分辨率跳变感（E04 的 1.5× 放大虚边不再出现）
- 布料动态：seg2 裙摆/发丝必须有 L1 级可见飘动，但轮廓主体不漂移
- 表情分层：omni 镜头逐段抽帧查肢体数（沿用 E04 V2.2 纪律）+ 神态是否符合分层描写
- 阿澈色温：sunprint 版母版与全片统一，不得带入 xiaoju_secret 的偏蓝调
