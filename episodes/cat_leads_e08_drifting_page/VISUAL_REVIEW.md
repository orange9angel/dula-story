# E08《漂走的那张画》视觉制作记录

## 2026-09-25：重新处理握笔、夹纸与交接手腕

用户指出上一轮拿笔、拿纸仍不自然。本轮继续修现有三维角色，保留已调整的年龄、步态、剧本、口型及原音轨。成片当前归档为 [2026_9_25.mp4](hybrid/output/2026_9_25.mp4)；[grasp_comparison.mp4](hybrid/output/grasp_comparison.mp4) **左上一轮、右当前版**，重点看 40.5–51.5 秒。上轮交付保存在 `before_grasp_fix.mp4`。重建命令见 [制作说明](hybrid/NOTES.md)。

- **握笔**：增加独立的拇指、食指、中指三点握姿，另两指收拢；缩细笔杆，纠正掌部在书本坐标中的方向。拇指从掌侧闭合，消除本轮检查发现的笔杆中心线贯穿拇指问题。本集派生五指蒙皮手并调整拇指比例，已认可的小雪手部保持原版。
- **扶本子与夹纸**：扶本子时四指轻搭上页；拿薄纸时拇指和食指在接近同一位置相对夹持，避免旧版虽然分处两面却没有夹在一起。阿澈从侧边递出，小蓝接住底边并收成阅读姿势，持握点不沿纸面滑动。
- **手腕与手肘**：求解同时考虑掌轴、前臂方向、肘部朝向和躯干间隙。小蓝伸手阶段按前臂来向调整掌部在纸面内的角度；阿澈翻起纸张时使用连续转腕曲线，消除逐时刻求最优解导致的突然翻腕。检查覆盖伸手、抬纸、交接和收纸，不能只看最后双手持纸的姿势。
- **作画运动**：按实际路径距离分配画线与跨笔画移动的时间，加入抬笔。旧版按顶点数量分配时间，长距离移笔可能挤在一帧内；现在笔尖、画线进度与手腕继续共用同一个采样结果。

最终成片 60 秒、1920×1080、30fps，共 1800 帧；完整渲染通过，65 个关键时点倒序跳转图像一致。骨长最大误差 `2.22e-16`，递纸锚点最大误差 `1.67e-16`，握笔锚点最大误差 `2.22e-16` 场景单位。作画另以 60Hz 采样：最大腕部折角约 `28.82°`，相邻采样的手肘与手腕位移分别不超过 `0.03384`、`0.03041` 场景单位。完整交接中持续夹持阶段，阿澈最大折角约 `69.47°`，小蓝左右手分别约 `41.00°`、`40.30°`；最大相邻采样掌部旋转 `7.11°`，未出现本轮曾发现的上百度突跳。

夹纸时拇指与食指骨端位于纸面两侧，面内偏差为 `0.002` 场景单位；握笔三个骨端距笔轴约 `0.0105–0.013`。9.5、41、43.5 秒三次实际变形网格检查中，笔杆中心线均无双面求交命中。这里的骨端距离不等于皮肤接触；中心线不相交不证明整根笔杆圆柱没有浅穿插，当前不是完整物理碰撞或指腹挤压模拟。

原、新 AAC 包流 SHA-256 均为 `036e59bf810c8b6fe2a9403876100870e362c8dd7e1f3640e858754301574827`。2814 个音频包的时间戳、时长、大小和标志一致，保留 AAC priming；没有重新配音、混音或变速。归档文件重新验哈希一致。

已从最终 MP4 解码检查全片概览、作画和 45–51.5 秒交接序列；另查看握笔、夹纸的七个近景机位。证据位于忽略目录 `hybrid/storyboard/` 的 `validation.json`、`media_validation.json`、`grasp_views.json`、`grasp_*.jpg` 与动作序列图。这些是几何检查和序列抽帧检查，不称作正常速度人工观片，效果仍待用户复看。发现与修法已写回 `direct-animation-craft` 主说明及 `references/episode-remake.md`。

## 2026-09-24：夹纸、走路与阿澈年龄修正

用户复看初版指出：拿纸手势不自然、小蓝走路像跺脚、阿澈外形比现有声音年幼。本轮保留原声及 60 秒时间轴，完成以下修正。

- **拿纸（45–51.5 秒）**：在现有五指蒙皮手中增加拇指与四指分处纸面两侧的夹持姿势，腕部留在纸边外。先调整本子在膝上的位置，再伸手夹纸、抬起递出；小蓝左手接稳后阿澈释放，小蓝右手再辅助收好。持握时握点固定，取消沿纸边滑动换位。放下后阿澈双手回到本子两侧。
- **走路（3.5–5.5 秒）**：重写为连续采样的轻步，摆动脚额外净空从 0.095 降为 0.032 场景单位，增加跟落掌离和停步缓冲；身体向前时脚底支点保持在世界空间，最后两步在离地阶段完成转向。
- **阿澈（8 秒后的对白及双人镜头）**：缩小头部、拉长下颌、收窄眼睛、去掉圆腮红；增加肩宽、上身与肢体长度，改为卡其长裤。配合坐姿调整凳高、书本位置和对白近景。声音不变，新的少年感仍待用户判断。

本轮输出仍为 `hybrid/output/output.mp4`。新增 `hybrid/output/refinement_comparison.mp4`，**左修正前、右修正后**；原三维版保存在 `before_refinement.mp4`。原二维与新版的对照仍为 `comparison.mp4`。

完整 1800 帧顺序渲染通过，65 个关键时点倒序跳转图像一致；固定骨长最大误差 `2.22e-16`，递纸接触点最大误差 `2.49e-16`，持笔最大误差 `1.11e-16` 场景单位。递纸另按 60Hz 检查。走路支撑锚点漂移为 0，实际鞋底顶点最大入地误差约 `9.8e-10`；拇指与食指末端变形皮肤在夹持平面两侧，最近距离分别约 0.00218 与 0.0000414 场景单位。这是几何验证，不代表完成整本道具的碰撞模拟或审美验收。

原、新 AAC 包流 SHA-256 仍为 `036e59bf810c8b6fe2a9403876100870e362c8dd7e1f3640e858754301574827`；没有重新配音、变速或混音。已从本轮最终 MP4 解码检查走路、画画、递接动作序列和全片概览。报告仍在 `hybrid/storyboard/validation.json` 与 `media_validation.json`；不将序列抽帧检查称作正常速度人工观片。

初版的接触锚点检查虽然通过，用户仍指出手势不自然，说明它只能证明位置约束，不能证明夹持动作成立。本轮已将这一点以及展示步态、声画年龄不一致的教训写入 `direct-animation-craft/references/episode-remake.md`。
