# E10《等雨停》分镜表

系列：《猫带我去的地方》。工艺：晴印 sunprint 平涂（全程序绘制版，零生成模型）。
总时长 76s，画布 1920×1080，30fps。三场景天气弧：河堤起风 → 白墙巷阵雨 →
便利店雨檐 → 雨后金光。

**本集定位**（系列圣经 §3.2 对齐）：
- **质感集**：F01/F02/F03 三条伏笔**全部静默**——不出现速写本符号、
  不出现小橘盯后山、不出现任何"夜里的光"话题。全片禁止出现 #3DFFC8 青色光。
- 老周不登场（冷却窗口纪律，同 E08）。
- 目标余韵：**温暖明亮**（一词定调：washed clean——雨把日常洗新）
- 情感落点：接 E08 阿澈"怕留不住普通日子"的伤口——雨后的街像新的一页，
  普通的日子会自己更新。
- 长剧集手法：E01 便利店、E02 白墙巷路线场景回调；"猫带我去的地方"标题语法
  再现（小橘带路）；结尾"新的一页"与 E08 画页意象呼应。
