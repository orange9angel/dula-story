# E06《模特小橘》制作笔记

> 正片打磨验证集：E05 导演复片后的改进验证——亮场景美术密度、
> 布料/微动回关键帧语法、I2V 收敛到全身位移。配音沿用 E05 V2
> （seed-tts-2.0 全角色：Girl=Vivi 2.0、Boy=小天 2.0、Cat=dayi）。

## 剧情

上午河堤，阿澈要给小橘画"正式肖像"。小橘端坐摆姿势却被蝴蝶勾走，
跳下台阶追蝴蝶；两人树荫下边看边聊。小橘玩累了回来睡着——阿澈
最后画成的是睡着的它。15 条目 / 60s / 10 句台词（Boy 3、Girl 5、
Cat 2，含一句睡猫梦话）。

## V1 验收记录（2026_9_5_1451.mp4，60.000s 1920×1080）

- **亮场景密度规则生效**：大树冠前景框架 + 台阶/草坡/河/远城三层纵深
  贯穿全片；结尾全景树荫转凉绿（色彩脚本）。晴印白天不再"空"。
- **布料/微动关键帧语法验证通过**：frame_05a/b 耳朵 A/B（0.6s 交替）和
  frame_17a/b 睡眠呼吸 A/B（0.9s 交替）用 codex 编辑式 prompt
  （change ONLY + pixel-identical）一次生成达标，除目标部位外构图一致；
  全片无布条形变（布料没走 I2V）。
- **I2V 收敛到 1 段**（猫跳下台阶跑向草地，满血 1080p）一次通过。
- **omni 10 镜全部一次通过**，含睡猫梦话（见翻车 1）。
- **台词时长**：seed-tts 无 rate，首轮 3 句超时（最坏 +1.04s），全部用
  加宽字幕窗/槽位解决（没动文本）；槽位级联改动集中在 14-32s 段。

## 翻车与新发现

1. **OmniHuman 会让睡着的角色睁眼**：shot10 底图双眼闭合，首版视频
   睁眼且瞳色绿变蓝。修复：prompt 强化"双眼始终闭合成柔和的弧线
   （全程不要睁眼）"，重 roll 通过。纪律：非典型面部状态（闭眼/眯眼）
   要在 prompt 里双重否定式强调。
2. **程序化半透明椭圆叠层在平涂画面上显假（E03 重复踩坑）**：
   dappleSway 的金色光斑椭圆叠在河面/人物上像灰色幽灵斑。关键帧本身
   已烘焙光斑，叠层冗余且难看——E06 全部撤掉，光斑只画进位图。
   已写回 i2v-motion-details.md 程序化图层边界。
3. **A/B 变体 prompt 纪律**：变体必须用"EDIT of the reference image +
   change ONLY X + everything else pixel-identical"句式，且只改一个部位；
   codex 一次通过率高（4/4）。
4. **seed-tts 时长只能靠槽位调**：加宽窗口时注意级联（omni 槽、I2V 槽、
   SFX 条目、后续静态帧 at 全部要动），build_timeline.py 是唯一权威。
5. **BGM v1 平曲翻车**：prompt 写"结构平稳起伏小"导致大模型出平曲
   （onset 149 但 RMS 近乎直线）。v2 按
   `dula-skills/episode-scoring/references/composition-prompt-craft.md`
   的曲式化 prompt 重生成：动态比 13→226，pp→mf→pp 弧线完整，
   已换入正片并重渲染（*_bgmv2.mp4）。决议：正式集 BGM 一律走 Seed-Audio
   大模型作曲 + 曲式化 prompt，不用网上曲库。
