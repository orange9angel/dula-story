# V5：后脑、腰缝和低位舞姿候选

本轮由用户指出后脑过大、前后像两个头、耳朵重复感、腰缝透出头发、双臂长期举起触发。
原文生图头部大小是保留基准；原曲、配音、130 个拍点、两次完整转身和统一三维角色保留。

首次新发壳方案被用户明确评价“两个人的颜值都急剧下降”，整片任务已停止。
该实验不能记为通过，`integration_v5_final` 只是当时的临时目录名，不代表最终版本。
后续 `integration_v5r2` 至 `r4` 为局部失败试验，仅留本地；当前查看的是 **r5 候选**。

当前恢复了 V4 的头面参数、原五官绘画、耳朵和原前发投影；没有重新画一张脸。
`CafeHairIntegration.js` 让头皮和所有发层一起收回负 Z 深度到原来的 0.62，XY 与 UV
保留。颈侧下方发束另按高度退到颌后。多个曲面仍存在，这不是拓扑合成一个网格，
也不是单张图重建出完整三维。侧面颜色仍沿用旧的视角加权绘画。

裙腰提高 5.1cm，裙长同增，保留下摆位置，消除站姿衬衫与腰带之间的空隙。
低位摆臂改为逐拍的落臂、单手回应与转身收臂；腕弯沿实际前臂限制。
旧裙裁切额外保护手臂蒙皮权重，避免低手经过旧裙高度时被误删。

实际视频的 26.8 秒还发现眨眼黑条：旧眼图底色采样混入眉毛/刘海。改为明确的干净
皮肤锚点，保留原眼形；闭合、半闭和睁开特写以及实际时间窗见 `tools/review_blink_v5.mjs`。
`storyboard/integration_v5/body_26_8_decoded.jpg` 特意保留修前黑条证据，不是最终帧。

## 对照和限制

- `storyboard/integration_v5/{Girl,Boy}_comparison.jpg`：原画、V4、当前正脸；V4/当前侧后面。
- `storyboard/turns/integration_v5r5/`：两人及同框共 27 张固定转面，正面头像恢复原有外观后再看侧后面。
- `config/unified_runtime_audit_v5.json`：同一演员实例、头发/头部有限值、两只真实耳朵和衣物代理。
- 侧发仍有贴图接缝，女主强侧面有折片，男主侧发有拉伸。头型收回有收益，不能因此宣称
  原画完全还原、头发全无缝或已获用户美术批准。
- 腿部胶囊和鞋底是有限采样，不证明全网格、头发、桌椅都无穿模。
- 目前用静态近景、抽帧、文件解码和数值检查复核；没有声称完成正常速度声画观看。

渲染入口现写 V5 文件，V4 输出与报告保留。原混音 SHA256 必须保持
`51d99f65cd5def2f6880e1ff94697a10a972bbc2a76b7e077d05686f1c65ce04`。
渲染器现在将浏览器 console error（包括 shader 编译失败）作为导出失败，避免生成缺头发的假成功视频。

复现：`node tools/render.mjs --full --wardrobe` 为 15.5–43 秒代表片段；完整片用
`node tools/render.mjs --full`。完整渲染完成后才可运行 `derive_dialogue_v5.py` 和
`verify_unified_v5.py`；二者从当前完整输出派生/核验，不能拿旧版本报告代替。
