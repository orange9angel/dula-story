# 三维唱跳修订

当前交付是统一聊天、唱跳人物并修订裙摆的 **V4 候选**，入口见
[README](../README.md)，制作与验收范围见 [UNIFIED_V4.md](UNIFIED_V4.md)。
V2 已获用户认可，随后转身、轻快卡点的历史修订见
[REFINEMENT_V3.md](REFINEMENT_V3.md)。下文保留 V2 的来源与验证记录；
其中渲染命令在当前源码下输出 V4，不用于复现旧版。

用户否决第一版的制作方向：需要二维原画风格的三维角色跳舞，不是整图网格变形。
当前修订用 `RiggedCafeKid` 接已有蒙皮身体，`CafeKid` 提供曲面头脸、绘画表情和
有厚度的头发层；已有全身原画直接投影到服装表面。左右转体、抬臂、肘膝和换步
实际发生在三维，头脸不始终朝摄影机。背景继续沿用日式咖啡厅。

  桌边聊天仍沿用原画局部口型。没有把整集称为全三维，也没有重生成歌曲/对白。

- `node tools/render.mjs --craft3d --full` 导出整集；`--craft3d` 导出试片；可加 `--check`。

身体复用本工作区既有 Tripo 160k LOD 与绑定，不是重新把小蓝/阿澈原图提交三维
生成服务。源 GLB 已复制到本集 `assets/models`，来源和哈希在
`config/craft3d_body_sources.json`。没有跨剧集加载执行代码，也没有本轮新付费生成。
不能因此声称复用的身体服装已经严格等于原画。

## 从原画对照发现的问题

| 部位 | 参考与实际差距 | 本轮处理与剩余限制 |
|---|---|---|
| 全身 | 简化曲面身体接精细头像时像白色模型；衣褶、鞋和肩袖明显不足 | 换已蒙皮身体，原画衣褶/裤纹进入真实表面；并未照原画重拓扑全身 |
| 头颈 | 初版男主头像小、颈部过长，连接留空 | 独立头部尺度/落位与连续颈根修正；不以统一缩放代替所有人物标定 |
| 衣物 | 女体原母体有背心/领结形状，色彩替换不消除轮廓 | 胸前局部压平、下摆收回、白衬衫投影；腰部与裙长仍不像原图，局部贴图拉伸可见 |
| 头发 | 正面保持生成发丝，但后脑圆帽和长发薄层不是完整大束 | 本轮只验证左右约 40° 转体及更小的相对转头；未证明 90°/背面成立 |
| 手脚 | 绑定坐标与画面左右不同，原脚踝高度不可直接沿用 | 手脚明确映射，按原模型中性脚踝标定；用真实蒙皮鞋底顶点检查接地 |

对照依据为 `assets/references/*_reference.png`、`assets/images/*_body_v1.png` /
`*_portrait_v1.png` 与 `storyboard/craft3d*/frame_*.jpg`。源绘画是独立美术依据，
三维自身截图不作为还原度证明。正常尺寸检查过全身、抬臂与浅斜面；背面未验收。

## 验证边界

身体为真实 SkinnedMesh；脸为实际曲面和动态绘画，头发为曲面层/后帽。没有逐帧
生成图或视频。18 秒首版检查了 18 个反向 seek 时刻，哈希一致；连续 1639 对支撑
采样最大帧间位移约 3.62mm，鞋底最低约 -0.81mm，支撑鞋底最高约 8.58mm。
这是一组局部网格采样，不覆盖全身自碰撞、衣裙或头发交叉。整集结果以
`config/craft3d_delivery_qc.json` 为准。

最终整集：3225 帧、1080p30、音视频均 107.5 秒，完整解码通过；30 个反向
seek 时刻一致。6731 对连续支撑采样最大约 3.64mm，最低鞋底 -0.94mm。
注册入口整理前后 30 张检查帧逐文件一致，`craft3d_catalog.json` 可发现两人及场景。

画风比平面网格版更接近所需运动机制，但还未达到原始文生图的精细程度；服装、
侧发和身体明暗仍是候选。完整正常速度声画、歌手分工与用户审美判断待评。
