# 全片统一三维角色修订

用户指出 V3 脸像面具，要求开场聊天也用唱跳时的三维人物。本轮沿用原对白、歌曲、
长蓝发与两人白衬衫，把开场、收尾和唱跳统一为同两个 `RiggedCafeKid` 实例。

随后用户明确：不限定自绘或图像映射等手段，只以最终融合效果判断。又指出裙子
仍有穿插、像贴上去。不能把第一次 V4 导出和数值通过写成这两项已经获得认可。

## 面部与身体

- 生产脸图只保留眉眼、鼻口和少量腮红细节；原图整张肤色、下颌描边不再决定脸部边界。
  五官仍画在头部曲面 UV 上，随头骨旋转，不使用朝向镜头的面片。
- 脸、耳和连续颈面统一光照方向与肤色响应。原配置漏了 `earX`，本轮补上实际耳廓。
  脸面曲率、鼻部起伏、颈根轮廓和领片一起调整，张嘴时有有限下颌几何位移。
- 第一版硬色阶在鼻下留下灰色横块，已收回鼻深并拓宽明暗过渡；不把加强阴影等同融合。
- 原导入裙摆坐下时被腿骨拉成折片；第一次简单裙壳仍被用户指出不融合。现在由
  `CafeSkirt.js` 提供带立体褶皱的连续裙面，按实际髋、膝位置落位并让下摆跟随动作；
  格纹沿衣料周长和纵向展开，保留腰带与白衬衫的覆盖。有限腿部胶囊拟合只约束布面，
  不改变原舞步。旧裙区与腿相连，删除后曾露出断腿空隙，已补同骨架驱动的连续腿面。
- 袖口附近的原衣物、发束横向纹理仍有细节差距。本轮不是全角度原画复原或新的完整网格重建。

## 三维聊天与场景

`scenes/CafeTable3D.js` 是实际桌椅、杯子、勺、画本和笔。日式咖啡厅远景仍使用已选背景板，
不加载含人物的 `cafe_table_v1.png`。两人坐姿、倾听转头、台词手势、起身由
`craft3d/dialogue-v4.js` 按 `script.story` 时段和原口型轨驱动。

勺沿实际手部握点布置，在原有两次敲击声处接近杯沿；笔的端点接到画本。
桌边与前方舞蹈区域用切镜省略行走，收尾同样切回桌边；没有宣称制作了完整往返行走。
所有角色始终保持三维实例，原舞蹈拍点和两次完整转圈保留。
