# Licensed opening music slot

Place a legally obtained 15-second clip here if you want to keep source material organized:

```text
pegasus_fantasy_opening.mp3
```

The episode currently includes a synthetic placeholder at:

```text
assets/audio/music/pegasus_fantasy_opening.wav
```

To use your licensed clip in the render, convert/trim it to that exact WAV path, then rerun:

```bash
npm run audio:seiya
npm run render:seiya
```
