# V2 修订（2026-08-28 凌晨）：口型/眨眼修复

观众反馈：猫和人的嘴部动画和表情都做坏了。

## 根因（三连坑，全是百炼 fallback 引入）

1. **矩形肤色补丁**：qwen-image-edit 全图编辑会把目标矩形内的皮肤/毛发整体重画
   （加红晕、改色调），v1 把整个实测矩形贴回基帧 → 12fps 口型切换时矩形补丁
   在脸上闪（E01 V5「矩形在闪」同性质）。
2. **喊叫嘴**：qwen 画的开嘴比基帧嘴大 3–4 倍且位置偏高，贴上后像脸上的黑洞；
   「微张」提示词也画成全开，半/开无区分。
3. **眨眼没闭上**：qwen 把闭眼画成半眯（眼球还在），frame_05/10 猫眨眼未生效。
   强约束 prompt（「眼球消失、眼睑合上、覆盖肤色/毛发」）实测仍不稳。

## 修复

1. v2 过渡版：「内容感知贴回」（relock_variants.py：在变体与基帧的强 diff 簇
   bbox 内贴回，位置自动对齐、重画皮肤被排除）救回了 3 个猫嘴 + frame_02/13
   猫眨眼——这些保留在成片里。
2. 少女口型 8 张 + 少女眨眼 6 张 + 猫眨眼 frame_05/10：00:39 codex 配额重置后
   全部用 E01 原工艺（codex 局部编辑 + auto_lock 羽化贴回）重做，一次通过。
   wanx 掩码重绘（眼睛也没闭上）和程序化画嘴（黑边椭圆太假）两条弯路废弃，
   记录在 generation_prompts.md。
3. rig 重建：v1/v2 混用按变体实际文件重算矩形（tools 内联脚本），
   check_lipsync 165 拍全过，全量重渲。
