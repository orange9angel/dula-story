# 《猫带我去的地方》E02《清晨河堤》分镜表

60 秒治愈系短片，接 E01《晴天便利店》次日清晨。内心独白驱动。
画风：「晴印」纯净版（同 E01 `STYLE_BIBLE.md`，逐字 hardLock；本集为**清晨低角度
阳光**：影子更长更斜，光斑偏暖金，其余规则不变）。
工艺：生成图 + Three.js 合成（沿用 E01 管线：母版锁 + 参考图链 + 审查纠偏），
**本集新增：连续动作镜头改用阿里百炼 wan2.6-i2v-flash 图生视频（3s / 720P /
无声，¥0.45/条），抽帧 12fps 进 cel 序列**；静止/对白镜头仍走 codex imagegen
文生图（fallback：百炼 wan2.7-image-pro，`gen_image.py`）。

## 角色设定锁（同 E01）

- **少女（小蓝）**：16 岁，及腰深蓝色长直发、琥珀色眼瞳、齐刘海；白色短袖衬衫、
  藏青格子百褶裙、黑色及膝袜、黑色乐福鞋。本集无伞无书包。
- **橘猫（小橘）**：橘色虎斑，白色胸毛与四爪，绿色眼睛；干燥蓬松。
- **场景锁 A（家·清晨）**：清晨小房间，低角度晨光斜照书桌与单人床，窗外亮蓝天。
- **场景锁 B（街道·清晨）**：晴空清晨的住宅区小巷，白围墙（**墙顶可行走**）、
  电线杆、绿树，地面长影与暖金光斑。
- **场景锁 C（坡道石阶）**：通往高处的上坡小巷，尽头一段石阶，两侧白围墙与绿植。
- **场景锁 D（河堤）**：坡顶外豁然开阔的河堤草地，晨光照亮的河面、堤沿石栏、
  远处桥影，草叶与蒲公英。
- **银幕方向**：小蓝始终朝画面右方行动；小橘始终在她前方/上方引导。
