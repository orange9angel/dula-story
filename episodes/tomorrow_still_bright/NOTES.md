# 《明天还会亮》tomorrow_still_bright — 制作笔记

## 立项

- 来源：`D:\Download\明天还会亮_完整动画剧本与分镜.docx`（提取件 `bible_source.txt`）。
  32 镜 / 480s / 16:9 / 2D 水彩手绘科幻短片。逐镜时长、画面、声音、表演节拍全部锁定。
- 用户指令：**用本集检验 cel-cinema 学习效果**（borrowed_moonlight R2-R5 全部教训）。
- 工艺：cel-cinema 管线（3D 底稿 → 文生图原画 → 绘画空间合成），全程执行六条交接纪律。

## 与上集的关键差异

- **几乎无对白**：EVA 播报 4 句 + 旧录音女孩 1 句 + 屏显 8 条 + 片名。无可见说话人
  （EVA 是画外播报、女孩是全息照片）→ 口型压力极小，重点转向**静默表演、停顿、
  接触时钟与环境音**。
- **主角是机器人**：无脸（单机械眼+光圈缩放）、三指左手+工具右手、左腿略短。
  表演全靠姿态、光圈、停顿——"禁止人脸与手指数变化"是硬性负面约束。
- **风格即水彩手绘**：铅笔轮廓+纸纹+克制赛璐璐阴影——最终画面必须完全是这个质感。

## 六条交接纪律的本集落实点

1. **绘画空间校准**：五场景母图到手后先标支撑面（廊道地面线/工作台高/驾驶舱座椅/
   舷窗台），M-07 90cm 身高按门高/抽屉高复核；工具车、电池、杯子的接触面逐镜核对。
2. **变体对应当前"表情"**：M-07 的"表情"=眼光圈状态（常态/缩小紧张/发亮惊喜/
   报警闪烁），光圈变体从对应姿势原画编辑；小苗两片叶数量锁死（负面约束）。
3. **配音年龄与表演**：EVA=程序化温柔播报（只报程序不解释情感）；女孩=旧录音的
   明亮少女感（R3 儿童声线教训直接适用）；句尾留白按 bible 节拍。
4. **声画最终时钟**：轮子吱响/腿部吱响跟实际推车与步伐触地、开关咔哒跟手指接触帧、
   焊接火星跟焊枪接触帧——全部从最终画面接触表导出，不估秒。
5. **连续播放独立审查**：本集全是长镜慢表演，波动/抖动风险最高——除 probe/seek 外，
   必须做整集连续抽帧复看（每镜首中末+过渡），静帧通过不算数。
6. **共享与归档**：通用件回 skill；原画/声音源留档带 source.json；LFS 纪律
   （推送前查全部未推送历史）。

## 音乐弧线（bible 六节，锁定）

保证 s19 片段与 s29 完整版是同一旋律。

## 关键表演节拍（bible 五节，逐镜锁进表演谱）

触叶 1.2s 伸/0.8s 停/1.8s 收；失效电池眼光先亮再缩静止 3s；腿部喜剧留 1s 静默；
焊接保护=火花瞬间伸手→意识到小苗不在→缓慢收回；结尾先看窗外再看小苗、肩部放松。

1. **Seed-Audio 素材自带前导淡入，攻击点内偏 0.18-0.44s**（电表滴 0.184、接管 0.405、
   开关咔哒 0.251）：直接按接触帧摆文件头=瞬头迟到。正法=event() 内测素材 RMS 首达
   15% 峰值的攻击点并回退摆放（impact 类）；连续滑动类（抽屉/门轴/车轮/发条）
   align=False，文件头=过程起点。首轮 meter×3 对位 ❌（+0.19s），修后 49/49。

3. **Suno「稀疏」prompt 产出并不稀疏**（202 onsets/167s，全段 mean -20dB）：无 2s 以上

4. **女孩旧录音底噪戛然**：bed_tape 铺 254.5-283，fade_out 0.05s 硬切承担 TAPE_CUT@283；

5. **whisper 数字回读伪差**（见上 v03 判例）：QC 工具对含大数字台词会低估拼音重合率，
   判读时先做数字归一，别把转写形式当发音错误。
