# 《猫带我去的地方》E04《夏夜流萤》分镜表

60 秒治愈系短片，接 E03《暮色归途》**同一天的夜晚**：晚饭后小橘蹲上墙头叫门，
小蓝悄悄跟它夜出，穿过夜晚的小巷和石桥，在河堤看见成片萤火虫。内心独白 +
**会说话的猫**（V1.1 起：不喵，直接说人话）双声部驱动。

画风：「晴印」夜晚变体（`STYLE_BIBLE.md` E04 节：天空深靛蓝→地平线暗紫、
星点平涂、月光冷蓝 rim、门灯/窗灯暖黄点光、萤火暖绿光点；零纹理等其余规则不变）。

工艺（V2.3 终版定型；开发期工艺演进见 V1_NOTES.md）：

- **说话镜头：OmniHuman 1.5 对口型视频**（即梦，图+音频→视频，1080P，
  姿态锁定 prompt，前垫帧对齐台词 lead）——取代贴回 cel 变体（E02–E04 三集
  验证 qwen/wanx/seedream 贴回全部不达标，codex 达标但被取代）。
  接入与纪律：`dula-skills/build-character-voice/references/volcano-omnihuman.md`。
- **连续动作镜头：seedance-2.0-mini**（火山方舟，4s 最短档取前段抽 12fps cel
  填 2-3s 槽；模型 ID 必须带日期后缀 `-260615`）。
- **配音：小蓝 = CosyVoice 龙华（定型不动）；小橘 = seed-tts-2.0 咪仔
  （黑猫侦探社角色音色 + emotion 参数）**。V1.1 起猫直接说话，无前置猫叫。
- **环境音/BGM：火山 Seed-Audio 1.0**（单要素模式，纯环境音/纯配乐 stem；
  环境音 prompt 必须显式锁"平稳无阵风"并跑 RMS 包络验收）。
- 程序化图层：starTwinkle 星点微闪 + fireflies 萤火（种子确定性）；
  E03 沿用的 dappleSway 光斑层已撤（坐标不通用，会画出假光斑）。

**银幕方向回正**：E03 归途全程向左；本集是夜出（出门集），全程向**右**，
猫在前方/上方引导。I2V 首帧构图沿用 E01/E02 规则：角色放画面**左** 1/3、
面向右、前方留空。

## 角色设定锁（同 E01/E02/E03）

- **少女（小蓝）**：16 岁，及腰深蓝色长直发、琥珀色眼瞳、齐刘海；白色短袖衬衫、
  藏青格子百褶裙、黑色及膝袜、黑色乐福鞋。无伞无书包。
- **橘猫（小橘）**：橘色虎斑，白色胸毛与四爪，绿色眼睛；干燥蓬松。
  **本集起开口说话**：声线走火山 seed-tts-2.0，性格=话少、淡定、小骄傲。
- **场景锁 A（巷口·家·夜）**：E03 巷口家门的夜晚版——门灯暖黄光斑、
  白围墙（墙顶可行走）、深靛蓝夜空。
- **场景锁 B（小巷·夜）**：E03 黄昏小巷的夜晚版——电线杆剪影、窗灯暖黄矩形
  更稀疏、路面月色冷蓝；纵深向右消退。
- **场景锁 C（石桥·夜）**：E03 石桥的夜晚版——低石栏杆、河面月光银带、
  左端接巷、右端接河堤。
- **场景锁 D（河堤·夜）**：E03 河堤的夜晚版——星空、草坡深绿近黑、
  **萤火虫由程序化层叠加**（母版不画萤火，留干净的夜空与草地）。
