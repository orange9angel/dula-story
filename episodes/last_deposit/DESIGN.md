# last_deposit Design Principles

> 环境音和配乐都是为了剧情服务的。  
> Every audio element and every visual detail must support the current story beat. If it doesn't have a clear narrative purpose, remove it.

## Core principle

No decorative filler. Music, SFX, ambience, model greebles, scene clutter, lighting — every choice must answer the question: **"What does this do for the story right now?"** If the answer is only "it looks cool" or "it sounds cool," cut it.

## Audio rules

1. **Dialogue is king.** SFX and music must duck or stay low enough to be understood.
2. **Music enters only when the scene emotion changes or action demands it.** No continuous wallpaper music.
3. **Sound effects must be motivated by on-screen action.** Engine when driving, impact when hitting, ambience when in a location.
4. **Avoid random decorative sounds.** No short "ding/woo" stingers unless they are a real, visible impact.
5. **Every added model or scene detail needs a clear narrative purpose.** If it doesn't help tell the story, cut it.

## Visual rules

1. **Robot details must read as functional mechanics.** Joints, armor plates, vents — not arbitrary decoration.
2. **Scene elements must reinforce location and mood.** Remove sky clutter, floating shapes, and busy background props that don't serve the shot.
3. **Color and glow should highlight characters and story focus,** not create visual noise.

## Edit checklist

Before adding or keeping any sound, model, or scene detail, ask:

**"Does this sound/model/scene detail have a clear purpose in this shot?"**
